# حزم القدرات — bundles/

الحزمة ليست تطبيقًا ولا Package ضخمة. هي **وصفة تركيب** تخبرنا ما القدرات التي يحتاجها نوع معين من التطبيقات.

الفائدة:

- نبني تطبيقًا خفيفًا من دون تحميل كل النظام.
- نعيد استخدام نفس حزمة الأمان/الصوت/التخزين في عدة تطبيقات.
- نستطيع لاحقًا بناء Tooling يقرأ `app.json` ويجمع ما يلزم فقط.
- تتغير الحزمة دون إجبار كل تطبيق على معرفة تفاصيل المكتبات والخدمات.

الحزم الحالية هي عقود معمارية، وليست كلها منفذة ككود مشترك بعد. قاعدة الاستخراج موضحة في `packages/README.md`.

أمثلة:

- `static-core.json`: تطبيق ممارسة خفيف يعمل محليًا.
- `legacy-child.json`: تطبيق طفل يحتاج أجهزة قديمة وصوتًا ببدائل قوية.
- `collaborative.json`: جلسات جماعية مباشرة.
- `ai-assisted.json`: قدرات AI خلف بوابة خادم موحدة.
- `full-learning.json`: تركيب أعمق عند الحاجة، وليس Default.
