# وحدة القراءة المتزامنة

`app360-read-along-v1.js` و`../css/app360-read-along-v1.css` مستقلان عن بيانات «حكاية وكلمة». يعملان بصيغة ES5، بلا إطار واجهة أو مكتبة تعرف على الكلام.

## عقد الدمج

1. أضف ملفي JavaScript وCSS.
2. اعرض النص عبر `APP360_READ_ALONG.markup(text, audioPath)`؛ يحفظ التشكيل والكلمة العربية متصلة وعلامات الترقيم والمسافات، ويهرب HTML.
3. أنشئ نسخة بـ`create({clock, resolve, fallback, fallbackBox})`. تعيد `clock()` كائنًا `{path, state, time}`؛ الوقت بالثواني من المشغل الفعلي، وحالة `playing` أو `waiting` أو `paused` أو `idle` أو `error`. لا تستخدم ساعة النقر أو مؤقتًا مقسمًا بالتساوي بين الكلمات.
4. تعيد `resolve(path)` رابط JSON أو بيانات مقطع مباشرة: `{text, language, duration, cues}`. المدة والتوقيت بالمللي ثانية، و`cues` عناصر `[wordIndex, startMs, endMs]`. تبدأ فهارس الكلمات من الصفر وفق وحدات النص غير البيضاء. ملف JSON يحتوي `{version:1, items:{audioPath:clipData}}`.
5. عند انتظار صوت جديد استدعِ `follow(path)`، وعند توقفه `stop()`، وبعد إعادة رسم النص `refresh()`. `warm(paths)` يهيئ بيانات المقاطع الحالية؛ طلبان متزامنان وحد ثمانية ملفات بيانات في الذاكرة. `destroy()` يزيل المستمعين ويوقف المتابعة.

حاوية `fallback` تعرض النص المنطوق الفعلي عندما لا يظهر نص مطابق في مجال الشاشة. حاوية `fallbackBox` تخفى بعد انتهاء الصوت. البيانات المفقودة لا تمنع تشغيل الصوت. التسجيل المحلي المخصص بلا توقيت لا يُنسب إلى نص مختلف. النصوص المعدلة لا تظلل مع صوت أصل مختلف؛ المقارنة تتجاهل التشكيل والترقيم فقط.

لتظليل كلمة في بنك الكلمات أثناء الجملة الكاملة، استخدم حاوية `data-ra-path` مع `data-ra-match="token"` وبداخلها عنصر `ra-token` وفهرسه `data-ra-index`. يمكن أن تتضمن الكلمة `markup()` آخر للصوت المنفرد؛ كل فهرس يتبع أقرب حاوية خاصة به.

تتبع الوحدة الساعة الفعلية كل 50 مللي ثانية أثناء المقطع فقط، وتكتب CSS عند تغير الكلمة. لا تتبع أثناء الصفحة المخفية، وتزيل التظليل عند الإيقاف والانتقال. `debug()` للتشخيص وليس جزءًا من تجربة الطفل.

## إنشاء التوقيت

استخرج التوقيت والصوت من عملية توليد واحدة أو طابق توقيتًا مراجَعًا مع التسجيل نفسه. في تطبيق الحكايات: `tools/prepare_arabic_reading.py` يضبط تشكيل النص؛ `tools/build_read_along.py --source-cache <scratch-directory>` يولد WordBoundary ثم يضغط MP3 ويزيح التوقيت بمقدار الصمت الخارجي المحذوف. تحمل المقاطع الجديدة Xing/LAME لإزالة تأخير وترحيل ترميز MP3 عند الفك. المقاطع الصوتية المعزولة تستخدم حدود إشارة الصوت، لا توقيت كلمات مفترضًا. تتأكد عملية البناء من مطابقة حروف كل كلمة وتغطية النص كاملًا.

الواجهة أثناء الاستخدام محلية؛ لا نطق شبكي ولا تعرف على صوت الطفل. اختبر العربية والتشكيل والإنجليزية والوقفات وتبديل المقاطع والإعادة والإيقاف والتخزين غير المتصل وبديل HTMLAudio في كل تطبيق جديد.
