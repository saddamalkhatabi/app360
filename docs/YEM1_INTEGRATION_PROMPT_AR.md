# تكامل yem1.com مع مدرسة العائلة 360

نفّذ في مشروع yem1.com واجهة الوصول إلى التطبيقات العملية لمدرسة العائلة 360، مع الحفاظ على نظام المستخدمين والريلز الحالي.

المصدر الحي: https://school.yem1.com/
دليل الروابط: https://school.yem1.com/links.html
الفهرس العام: https://school.yem1.com/data/public-links.json

اقرأ الفهرس JSON ذي schema_version=1. يحتوي ages على id وtitle_ar وurl وembed_url، ويحتوي apps على id وtitle_ar وage_group وaudience وurl وembed_url وcover وrelease_channel. اعرض التطبيقات بحسب عمر الطفل المختار، مع إمكانية تغيير فئة العرض دون تعديل عمر الطفل. استخدم الروابط الواردة في الفهرس كما هي، ولا تخمّن أسماء المجلدات. الفئات الخالية تعرض رسالة مناسبة. أضف مدخلاً «التطبيقات العملية» في واجهة الريلز والمدرب والأطفال، وبطاقات واضحة تفتح التطبيق بلمسة، وزر فتح في صفحة مستقلة ومشاركة الرابط العام. لا تربط فيديوهات بعينها بتطبيقات الآن؛ تلك مرحلة لاحقة.

افتح embed_url داخل iframe في لوحة متجاوبة قابلة للإغلاق بزر وبمفتاح Escape، وأعد التركيز للزر الذي فتحها. امنع تمرير خلفية اللوحة أثناء فتحها وأعده عند الإغلاق. حافظ على عنوان التطبيق والفئة الحالية وزر فتح خارجي احتياطي. استخدم allow="autoplay; fullscreen; clipboard-write; web-share" وtitle واضحاً. إذا استعملت sandbox، فأضف allow-scripts allow-same-origin allow-forms allow-popups allow-downloads؛ لا تسمح بالتنقل إلى أعلى الصفحة. الصوت قد يحتاج نقرة المستخدم الأولى. تجنّب تغيير src عند كل إعادة رسم في الواجهة حتى لا تعيد تشغيل اللعبة.

تبادل postMessage بإصدار version=1. يقبل الإطار رسالة {type:"app360:navigate",version:1,age_group:"4-8"} أو {type:"app360:navigate",version:1,app_id:"a4-command-path"}. استخدم targetOrigin="https://school.yem1.com" دائماً. عند الاستقبال تحقق من event.origin==="https://school.yem1.com" ومن event.source===iframe.contentWindow. الرسائل المتاحة: app360:ready يتضمن catalog_url، وapp360:state يتضمن app_id وage_group، وapp360:height يتضمن height. طبّق حدوداً معقولة لارتفاع الإطار ومنع اهتزاز التخطيط؛ اللوحة ذات الارتفاع الثابت يمكنها تجاهل height. لا تستخدم targetOrigin="*" ولا تنفذ URLs أو HTML واردة بالرسائل.

هذه المرحلة لا تتضمن تسجيل دخول مشتركاً أو نقل بيانات الأطفال. المدرسة تدعم ملفات أطفال محلية ذات id ثابت وname وage_group وexternal_id=null، وقائمة منفصلة لكل حساب محلي معروف. هي ملفات جهاز وليست حسابات مصادقاً عليها أو صلاحيات وصول. لا ترسل أسماء الأطفال أو كلمات المرور أو tokens في URL أو postMessage، ولا تفترض أن التخزين داخل iframe مشترك بين جميع الأجهزة أو المتصفحات. الربط المستقبلي يحتاج API مصادقاً عليه وتحقيق ملكية الطفل وتبادل رموز قصيرة العمر من الخادم، وسيُنفّذ لاحقاً بشكل مستقل.

جلب الفهرس مسموح من https://yem1.com وhttps://www.yem1.com في خادم Node. لبيئات تطوير أخرى استخدم جلباً من خادم yem1.com أو نسخة محلية للاختبار، ولا توسّع صلاحيات APIs الخاصة. احتفظ بنسخة فهرس مؤقتة مع معالجة فشل الشبكة وزر إعادة المحاولة. اختبر الهاتف والتابلت والحاسوب، اختيار طفلين بفئتين مختلفتين، فتح الفئة مباشرة، التطبيق المباشر، المشاركة والنسخ الاحتياطي، إغلاق الإطار والعودة للريلز، وحفظ التقدم بعد الرجوع. ميزات PWA والتثبيت والشبكة المحلية قد تختلف داخل iframe؛ وفر فتحاً خارجياً دائماً.

التحديث موجود أولاً في فرع family-school-360-preview. روابط school.yem1.com الواردة هنا تصبح جاهزة بهذه الميزات بعد نشر التحديث إلى البيئة الحية؛ لا تنشر المشروع الآخر أو تغيّر مصادقة المستخدمين تلقائياً.
