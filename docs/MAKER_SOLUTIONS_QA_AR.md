# مراجعة ورشة الحلول — المعاينة التقنية

التطبيق `a4-maker-solutions`، المسار `apps/4-8/maker-solutions-lab/`، بتاريخ 2026-10-08. النسخة قناة معاينة وليست قبولًا تربويًا أو اختبارًا ميدانيًا على Big TAB.

## ما اكتمل

ستة مشروعات، وثلاثة مسارات استعداد لكل مشروع. حلقة الخطة والتصميم الأول والاختبار والتحسين بجزء واحد والاختبار الثاني والمقارنة تعمل. نماذج SVG تتغير مباشرة مع الأزرار، ورسم اختياري بالعقد المشترك، وخطة مواد وخطوات قابلة للطباعة. فرق صريح بين قواعد الشاشة والملاحظات الواقعية، دون تحويل نقرة إلى تجربة بناء حقيقية.

204 تسجيلات MP3 عربية وإنجليزية للتعليمات والحاجات والشروط وبروتوكول الاختبار واختيارات التصميم. يتطابق النص المنطوق وحدود كلماته مع التسجيل، وتظليل الكلمات قابل للتحكم عبر إعداد العائلة. صوت النص المؤلف العام له بديل جهاز، والنص يبقى عند فشل الصوت؛ لا تُرسل الملاحظات الخاصة إلى التوليد الصوتي.

## تحقق ناجح

- 12 اختبار نموذج ومحتوى: المشروعات الستة، عدم تعديل النموذج الأول، بروتوكول ثابت، منع صفر/عدة تغييرات، قبول ملاحظة إخفاق النموذج، شروط التسجيل الواقعي، الهوية المستقلة، رفض الاستيراد غير المكتمل والنتائج المزورة، رسم آمن، خصوصية التصدير، وتوقيت كلمات جميع التسجيلات.
- 64 فحصًا عبر واجهة Chrome Headless 155: دورات المشروعات الستة، مسارات entry/practice/extend، نموذج شاشة وبناء واقعي بمدخلات اختبار وهمية، إعادة الفتح واستعادة ملاحظة الاختبار والتأكيد، معرض المقارنات، مخطط الطباعة، تصدير ملف حقيقي، استيراد نسخة سليمة ورفض ملف تالف، وقالب مدرب مستقل.
- ملفات طفلين بالاسم نفسه وفئتين مختلفتين عبر API الأسرة الحقيقي: لا تظهر مسودة الطفل الأول للثاني، وتعود عند إعادة اختيار الأول.
- صوت مسجل مع تظليل كلمة من الساعة الفعلية؛ إيقاف التظليل، الإنجليزية LTR والعربية RTL، منع ضيف الأسرة غير المساعد من إدارة القوالب.
- المقاسات 360×640 و412×915 و768×1024 و1024×768 و1366×768: لا تجاوز أفقي في المكتبة والخطة والتصميم والمقارنة، انتقال مرحلة واحد عند الضغط، وتغيير الاتجاه دون فقد المحاولة.
- رفض localStorage: الحلقة تكتمل مع تنبيه أن الحفظ مؤقت. ملف JSON تالف: رسالة واضحة، والأصل لا يكتب فوقه.
- التنزيل عبر واجهة مدير المنصة الفعلية ثم قطع الاتصال: إعادة تحميل المكتبة وتشغيل اختبار النموذج بنجاح. 3 اختبارات سلامة حزم Offline وبصمات الملفات والعامل المشترك ناجحة.
- مسار `launch.html?project=house` يفتح المشروع ويصدر ready في سجل عقد التشغيل.
- تحليل JavaScript الأساسي بمعيار ES5 ناجح، وكذلك مدقق المتطلبات وطبقة الواجهة المشتركة وحداثة blueprints.
- 26 اختبارًا للبوابة والتنقل الأسري والفيديوهات وخادم relay ناجحة.

## حدود وملاحظات المشروع السابقة

لا تدعي هذه المراجعة اختبار Big TAB Android 4.4.2 فعليًا، أو مراجعة صوت بشرية مستقلة، أو تجربة ملاءمة أسرية بموافقة ولي الأمر. يلزم إنجازها قبل اعتبار النسخة معتمدة تربويًا. فحص مخطط الطباعة هنا عبر DOM والرسومات، وليس تجربة طابعة ورقية فعلية.

المدقق العام `validate-platform-active.js` يتوقف على أخطاء موجودة في HEAD السابق `6728954`: بيانات a1-plan-runner وa1-routine وقدرات a1-calm غير المسجلة. مدقق الروابط له ستة إخفاقات سابقة في تطبيقات 1–4، تتعلق باستعلام النسخة ومسارات الإطلاق المباشرة. اختبار test-platform المرتبط بهذه المدققات يفشل أيضًا في خط الأساس نفسه. تمت مقارنة هذه النتائج بنسخة منفصلة من HEAD السابق؛ لا توجد إضافة جديدة من ورشة الحلول إلى تلك الإخفاقات. لم تُوسّع هذه المهمة إلى إصلاح التطبيقات الأخرى.

الحفظ محلي ولا يوجد SSO جديد. مرجع مختبر لماذا في رابط وسجل الإطلاق فقط؛ لا استيراد تلقائي لمحاولات التطبيقات الأخرى. نشر فرع المعاينة لا ينشر main أو خدمة الإنتاج.

No people, tools, text or typography.
