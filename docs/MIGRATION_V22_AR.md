# ترحيل V22 — تطبيق الرسم والكتابة

بتاريخ 2026-09-12 تم نقل المصدر العامل لتطبيق الرسم ومسك القلم والكتابة المبكرة من المسار التاريخي:

```text
1-4/
```

إلى المسار القياسي:

```text
apps/1-4/drawing-writing-foundations/
```

## ما الذي تم الحفاظ عليه؟

- ملفات الصوت الحالية وحزم الأسماء والألوان.
- PCM fallback للأجهزة القديمة.
- الواجهة وسلوك القلم.
- المزامنة الجماعية.
- PWA وService Worker بعد تغيير Scope إلى المسار الجديد.
- روابط المشاركة داخل التطبيق بعد تحديث fallback URL.

## ما الذي تغير؟

- أصبح التطبيق Workspace مستقلًا وله `app.json` و`package.json` وREADME.
- Build انتقل إلى V22 لأن المسار وPWA scope والكاش تغيرت.
- حذف Runtime snapshots غير المستخدمة (`audio-v13` إلى إصدارات تاريخية غير مستخدمة) من الشجرة الحالية؛ تبقى محفوظة في Git history.
- `/1-4/` أصبح Compatibility Gateway فقط يحول الرابط القديم إلى المسار الجديد.
- تم تنظيف Workflows/Scripts أحادية الاستخدام للإصدارات V11–V21 من مناطق CI النشطة بعد نجاح الترحيل.

## لماذا أبقينا /1-4؟

لكي لا نكسر:

- Bookmarks قديمة.
- روابط سبق نشرها.
- start_url لتثبيت PWA سابق.
- مستخدمًا يفتح الرابط القديم يدويًا.

لا يضاف كود جديد هناك.

## سياسة الاستخراج بعد الترحيل

الصوت والمزامنة والتوافق Legacy ما زالت داخل التطبيق، عمدًا. عندما يحتاج تطبيق ثانٍ أحد هذه الأجزاء، ننفذ Extraction إلى `packages/` و/أو `resources/` مع اختبارات Compatibility. لا ننسخ الملفات إلى التطبيق الثاني.
