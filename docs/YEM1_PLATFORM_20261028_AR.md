# بنية المنصة الجديدة

مركز الهوية: `https://yem1.com`، الريلز: `https://rails.yem1.com`، المدرسة: `https://school.yem1.com`.

يحتفظ الريلز بقاعدته ومحتواه واشتراكاته. مصدر الحسابات والأطفال والصلاحيات أصبح YEM1 عند تفعيل `YEM1_IDENTITY_ENABLED=1`. يبقى في الريلز إسقاط تقني للأرقام اللازمة لعلاقات المحتوى والتقارير، دون قبول كلمات مرور محلية مستقلة. لكل تطبيق قاعدة ومجلدات migrations وseeds خاصة به.

دليل النقل الكامل في مستودع yem1: `docs/DEPLOYMENT_AR.md`. لا تفعّل الهوية المركزية على قاعدة الريلز القديمة قبل نقل هوياتها. لا تنشر ملفات `.env` أو `config/local` أو `*.private.json`.

المدير الشامل يدير هويات المنصة وصلاحيات كل منتج من `yem1.com/admin`. إدارة محتوى الريلز واشتراكاته من `rails.yem1.com/admin`، وإدارة المدرسة وتقاريرها من `school.yem1.com/admin`. جلسة ولي الأمر منفصلة عن جلسة الطفل؛ توحيد الدخول يعمل داخل المستوى نفسه.

النسخة المستضافة تُبنى من GitHub على Node.js 22، Build: `npm run build`، Start: `node server.js`. محتوى الريلز المعتمد موجود في `seeds/content` وتطبّق عليه ملفات مراجعة المحتوى في `config`. البيانات التشغيلية الخاصة بالأسر لا تُضمّن في المستودع.
