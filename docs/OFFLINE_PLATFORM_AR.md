# التنزيل والعمل دون اتصال

الحفظ عند الاستخدام هو الافتراضي. جميع عمال الخدمة في التطبيقات وفي البوابة يستوردون `assets/js/offline-worker-v1.js`؛ لا تُحمّل مكتبة تطبيق أثناء تثبيت عامل الخدمة. الزيارة الأولى تحفظ الصفحة والموارد التي حمّلها المتصفح بالفعل، ثم تحفظ الطلبات اللاحقة تلقائيًا. الصفحة الرئيسية تتيح تنزيلًا كاملًا مستقلًا لكل تطبيق عبر SweetAlert2 محلي، وفرزًا بجميع الفئات العمرية.

## إضافة تطبيق وتحديثه

1. اجعل `app.json` يحمل الحالة `live`، أو فعّلها في `data/live-overrides.json`، وسجّل مجلد التطبيق في `data/offline-dependencies.json` مع الملفات المشتركة الخارجية التي يعتمد عليها. الملفات الموجودة داخل التطبيق تُجمع تلقائيًا، عدا الأدوات والاختبارات والوثائق.
2. استخدم عامل الخدمة المشترك وأدرج `offline-client-v1.js` في صفحة التطبيق. البوابة تدعم عاملها ذي النطاق العام أيضًا.
3. شغّل `npm run build:offline` بعد أي تغيير في ملفات التشغيل أو الصور أو الصوت أو البيانات أو سياسة التحديث. ثم شغّل `npm run test:offline`.
4. انشر التطبيق وملفات `data/offline/` و`data/offline-catalog.json` معًا. بصمة محتوى الحزمة تغيّر الإصدار تلقائيًا، حتى لو نُسي تغيير رقم `app.json`.

الأحجام المعروضة مجموع أحجام الملفات الأصلية، وليست حجم النقل المضغوط أو استهلاك التخزين النهائي. بعض التطبيقات تتضمن مكتبة تهنئة أسماء مشتركة كبيرة؛ حجمها داخل الحزمة مُحتسب. التنزيل متسلسل، ويتحقق من SHA-256 حيث تتوفر Web Crypto، ثم يحتفظ بالملفات الناجحة للاستكمال. إعلان الجاهزية يأتي بعد نجاح كل الملفات وكتابة علامة اكتمال. صفحة الإدارة تفحص العلامة وعدد الملفات مجددًا، فحذف المتصفح للملفات لا يتحول إلى ادعاء جاهزية كاذب.

## التحديث المطلوب

ضع داخل `data/offline-policy.json` مثلًا:

```json
{"schema":1,"apps":{"a4-command-path":{"required":true,"note_ar":"هذا التحديث يصلح مشكلة مهمة؛ يرجى تنزيله قبل المتابعة."}}}
```

يمكن وضع `minimumVersion` ببصمة حزمة سابقة لا تزال مقبولة. إذا كانت النسخة المنزلة أقدم وغير مقبولة وتحقق الموقع من القائمة الجديدة عبر الإنترنت، يُطلب تحديثها قبل فتحها. الصفحة المباشرة للتطبيق تعرض حاجز تحديث أيضًا. عند انقطاع الشبكة أو تعذر الوصول إلى قائمة الإصدارات، تبقى النسخة المحلية متاحة؛ لا يمكن ضمان إلزام جهاز غير متصل بإصدار لم يصله. التطبيق غير المنزّل يعمل بأحدث الملفات المنشورة عند الاتصال.

الحزمة الجديدة تكتب في مخزن منفصل. لا تتغير النسخة النشطة ولا تُحذف السابقة حتى ينجح التنزيل بأكمله. لا يُعاد تحميل لعبة الطفل تلقائيًا نتيجة التنزيل. لا يُبدّل التحديث الملفات داخل جلسة مفتوحة؛ افتح التطبيق من جديد لتستخدم الحزمة الجديدة.

## التشغيل والحدود

- يحتاج العمل دون اتصال إلى HTTPS في السيرفر الفعلي، أو localhost أثناء الاختبار، ومتصفح يدعم Service Worker وCache Storage. مجرد سيرفر Node عبر HTTP على عنوان عام لا يكفي.
- يعمل رابط الاختبار الثابت إذا كان نطاقه يسمح بعامل الخدمة؛ إذا كانت المعاينة داخل إطار يمنع التخزين أو عامل الخدمة، افتح الرابط مباشرةً. التشغيل الفعلي على النطاق نفسه يحافظ على التنزيلات؛ تغيير نطاق أو مسار نسخة الاختبار ينشئ مخزنًا مستقلًا.
- الروابط إلى تطبيقات أخرى تتطلب تنزيل تلك التطبيقات بشكل مستقل. المزامنة العائلية والحسابات والذكاء الاصطناعي والتهنئة السحابية تحتاج اتصالًا. الأنشطة والمواد المحلية هي المقصودة بالتنزيل الكامل. طلبات API والمصادقة خارج التخزين.
- أغلق شاشة التنزيل إن أردت، لكن اترك الصفحة نفسها مفتوحة. إغلاق الصفحة يوقف المهمة؛ الاستكمال يعيد استخدام الملفات المكتملة. لا يعد النظام بتنزيل خلفي بعد إغلاق المتصفح.
- نقص المساحة أو حذف المتصفح للتخزين قد يزيل التنزيلات. تظهر حالة خطأ قابلة للاستكمال. حذف التنزيل الكامل لا يحذف تقدم الطفل ولا الحفظ التلقائي لما استخدمه سابقًا.
- سيرفر `services/family-relay/src/server.js` يرسل ملفات عامل الخدمة وقوائم الإصدارات دون تخزين HTTP طويل. تتحقق آلية التنزيل من HTML بعد إزالة إضافة إعداد Relay المعروفة فقط؛ بقية الملفات يجب أن تطابق بصمتها.
- الملفات القديمة لعمال الخدمة السابقة تبقى منفصلة ولا تُعلن جاهزيتها ضمن المدير الجديد. لا تُحذف بيانات الطفل عند ترقية الاستراتيجية.

SweetAlert2 11.23.0 مضمنة محليًا في `assets/vendor/` لتعمل نافذة الإدارة دون اتصال بعد تحميلها؛ حقوقها وترخيص MIT في ترويسة الملف.

## التحقق في المتصفح

شغّل `APP360_TEST_CHROMIUM=/path/to/chromium node tooling/test-offline-browser.cjs` مع Playwright متاح في بيئتك. يختبر شاشة الهاتف والفئات والإيقاف والاستكمال، وفشل التحديث مع الاحتفاظ بالنسخة القديمة، وحاجز التحديث المطلوب، ثم يقطع الاتصال ويعيد فتح التطبيق والبوابة. اختبار الروبوت الكامل: `NODE_PATH=/path/to/node_modules CHROMIUM_PATH=/path/to/chromium node apps/4-8/command-path-lab/tools/test-variety-offline-browser.cjs`. اختبارات فهارس المنصة العامة تحتوي أصلًا على تعارضات بيانات في مخطط الجلسات والروتين وبعض القدرات؛ ليست ناتجة عن نظام التنزيل. بعض اختبارات الواجهة القديمة ما زالت تفترض أرقام إصدارات قديمة.
