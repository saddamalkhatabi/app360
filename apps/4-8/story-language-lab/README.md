# حكاية وكلمة: أسمع وأقرأ وأؤلف

أول تطبيق للفئة 4–8، هوية `a4-story-language`. نسخة تقنية تجريبية على فرع `family-school-360-preview` فقط؛ لا تحديث Railway أو main.

6 حكايات مستقلة لكل لغة، و16 مشهدًا و12 ورشة كلمة و113 ملف صوت محلي. تسمح الحلقة بالاستماع والحوار وترتيب الصور وفهم الحدث وبناء كلمة متصلة أو صوتية، ثم تأليف وحفظ نهاية ومراجعة المساعدة. القراءة والتسجيل اختياريان، ولا درجات للنطق أو مقارنة للأطفال.

الاستعداد مدخل/ممارسة/توسع يغيّر عدد مشاهد المهمة (3 أو 4)، والتأليف من 2–5 صور. تغيير الاستعداد لا يحذف الحكاية المؤلفة. مكتب المدرب ينسخ قالبًا بعنوان وتعليمة خاصة دون تغيير الأصل، ويضبط الدعم ويحتفظ بملاحظة وصفية محلية. ضيف الجلسة العضو يواصل الحكايات دون إدارة المكتب؛ المسؤول ومساعده يديرانه.

حفظ تلقائي محلي بهوية مستخدم المدرسة وschema مستقلة، واستعادة بعد الإغلاق والتدوير. رفض التخزين يترك الحلقة في الذاكرة مع تنبيه وتصدير. ملف تالف لا يستبدل بصمت. رف للحكايات المحفوظة مع القراءة وتعديل نسخة وحذف وطباعة وتصدير/استعادة JSON بمشاهد المكتبة فقط. التصدير يستبعد التسجيلات وهوية المستخدم وسجل المحاولات وملاحظات المدرب.

تسجيل اختياري حتى 60 ثانية عبر إذن الميكروفون وIndexedDB محليًا فقط. عدم الدعم أو رفض الإذن لا يمنع الحكي أو الكتابة. الصور والصوت محلية في كاش ذري؛ لا إعلان Offline حتى ينجح تحميل الحزمة كاملة. الكاش الخاص لا يحذف كاش تطبيق آخر. ES5 وFlexbox وأزرار بدل السحب مع Touch Guard المشترك. PWA والتسجيل إضافات حسب دعم المتصفح.

## الأصول

أُنشئت صورة الغلاف `assets/covers/a4-story-language-v1.png` وأوراق الكوب والكرة والقطة بأداة `image_gen.imagegen` المدمجة، دون تعديل raster. تُعرض الأرباع بقص CSS. [المطالبات والمسارات الكاملة](data/asset-provenance.json). قصة الباب والأشياء والأيقونة SVG أصلية. الكوب والكرة والكتاب مراجع مباشرة إلى مورد المشروع الأصلي `resources/early-child-visuals`؛ لا كود مستورد من تطبيق سابق.

[المحتوى](data/stories.json) و[نصوص الصوت ومصادره](data/audio-manifest.json). الرواية والمفردات مولدة وقت البناء عبر `edge-tts` بأصوات `ar-SA-ZariyahNeural` و`en-US-JennyNeural`. المقاطع/الأصوات بأداة eSpeak NG بالترميز الصوتي، وليست أسماء الحروف. كلها أمثلة اصطناعية للمساعدة؛ مراجعة سمعية مع المدرب مطلوبة خصوصًا المقاطع العربية المشددة، ولا تقييم للنطق. لا خدمة صوت أو مفتاح API في استخدام الطفل.

لإعادة توليد الصوت: Python مع `edge-tts` و`ffmpeg`، ومسار eSpeak NG 1.51 المستخرج في `STORY_ESPEAK_ROOT`، ثم `python tools/build_audio.py`. أدوات بناء فقط. شهادات TLS تُتحقق؛ يستخدم proxy البيئة إن وجد.

`CONTENT_SEEDS.json` وثيقة التخطيط الأصلية؛ تحققت أفكارها الست في بيانات التشغيل. قراءة المتطلبات ومواصفات البناء والبنية المشتركة سبقت التنفيذ. تجربة الأسرة والمراجعة السمعية والجهاز Big TAB الفعلي تنتظر قبول الإنتاج؛ لا ادعاء أثر تربوي أو اختبار جهاز لم يتوفر.
