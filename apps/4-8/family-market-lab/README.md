# سوق العائلة: أعدّ وأقسم وأوازن

معاينة 2 في فرع `family-school-360-preview`. يعمل التطبيق مستقلًا أو داخل بوابة مدرسة العائلة 360. التجربة الأسرية ومراجعة الصوت على الأجهزة الفعلية ما زالتا قيد الانتظار.

## دخول الطفل

اختر عالم الصور ثم اضغط بطاقة تجربة كاملة. تتوفر عشر تجارب واضحة: العد، إكمال الناقص، إعادة الزائد، التوزيع بالتساوي، التقسيم، ضم مجموعتين، طلب من صورتين، المقارنة، النمط، والقياس. لا توجد بوابة درجات. يغير زر «تجربة جديدة» الصورة والكميات ضمن المجال المناسب؛ يتجنب المحرك التكرارات الحديثة متى سمح مجال الصور والأعداد بذلك.

زر «أسمع المطلوب» يقرأ التعليمات والكمية واسم الصورة. زر «أرني كيف ألعب» يعرض أول خطوتين في نسخة مستقلة دون تغيير محاولة الطفل. الإضافة والإعادة بالنقر، والسحب له بديل بالأزرار. تعرض المقارنة «الصف الأول» و«الصف الثاني»؛ تعرض قواعد النمط بالصور والكلمات في العربية.

| المستوى المرن | العمر الإرشادي | المجال الافتراضي |
| --- | --- | --- |
| أعدّ وأطابق | 4–5 | حتى ٥ بطاقات |
| أكمل وأقسّم | 5–6 | حتى ٨ بطاقات |
| أجمع وأوازن | 6–7 | حتى ١٢ بطاقة |
| أفسّر وأصمّم | 7–8 | حتى ٢٠ بطاقة |

المقارنة والقياس محدودان افتراضيًا بثماني بطاقات، والكمية في التوزيع تقبل القسمة على السلال. تُحفظ المهام القديمة الـ32 وروابطها والأعمال السابقة. المستويات إرشادية يختارها المرافق حسب الاستعداد.

## مكتب المربي

يبني المربي نمطًا من نوع تجربة وعالم وصور محددة وحد أدنى وأقصى، ثم يختار التنويع أو الزيادة التدريجية. للتوزيع يحدد السلال، وللنمط يختار تناوب صورتين أو تكرار صورة أو ثلاث صور. تظهر الحدود غير الصالحة قبل التشغيل. يمكن تجربة النمط، أو حفظه ضمن عشرين نمطًا جاهزًا تظهر للطفل بنقرة، أو تصديره واستيراده. تعديل نمط محفوظ يفتح نسخة؛ حذف النمط يحتاج نقرتين.

[استراتيجية التجارب والتعليمات](EXPERIENCE_STRATEGY_AR.md) تشرح أهداف الأنشطة وكيفية استخدام التنويع دون إرهاق الطفل.

## الصور والصوت

- فهرس مشترك من **43 صورة موجودة و86 تسجيلًا لأسماء الأشياء** في سبعة عوالم: الفواكه والخضروات والألعاب والمدرسة والمنزل والحيوانات والمواصلات. يُشير مباشرة إلى الملفات الأصلية في `apps/1-4/say-and-name` دون نسخها أو تعديل التطبيق السابق.
- يستعمل 22 تسجيلًا أصليًا للأعداد من صفر إلى عشرة بالعربية والإنجليزية؛ للمحتوى المؤلف والأعداد الأعلى **206 ملف MP3** داخل هذا التطبيق، تشمل العد حتى ٢٦ عندما يضع الطفل بطاقات زائدة؛ أهداف الطلبات تبقى حتى ٢٠. ملفا الفهرسة والتتبع يوثقان المدة وحدود الكلمات الفعلية.
- **العدد يُنطق بلغة النشاط**: العربية في الوضع العربي والإنجليزية في الوضع الإنجليزي. الأرقام العربية مرئية كذلك. النص الجديد يحول الأعداد من صفر إلى ستة وعشرين إلى كلمات اللغة قبل النطق.
- التعليمات المؤلفة تتبع الكلمات بتوقيت التسجيل الحقيقي. تسجيلات الاسم والعدد الأصلية تظلل الاسم أو العدد كاملًا أثناء تشغيله؛ لا توجد توقيتات كلمات مُخمنة لهذه التسجيلات.
- خيار تتبع الكلمات في مكتب المربي وفي تفاصيل اللعب يستخدم إعداد الأسرة المشترك. المسؤول والمساعد المخول يختاران المجموعة أو متعلمًا محددًا؛ الضيف يتبع الإعداد. إيقاف التتبع يبقي الصوت يعمل.
- النص الجديد يستخدم صوتًا محليًا مناسبًا على الجهاز، يفصل العربية والإنجليزية ويتجاوز الترقيم ويصحح نطق عُمَر. عند غياب صوت مناسب تستمر الممارسة والتعليمات المسجلة؛ يمكن للمرافق حكي النص الجديد. لا ميكروفون مطلوب ولا إرسال لنص الطفل إلى خدمة خارجية.

## الحفظ وOffline

لكل ملف أسري حفظ مستقل تحت `app360:a4-family-market:schema-1:<profile>`. المسودة والتراجع والمحاولات تبقى محليًا. آخر عشرين محاولة تلقائية في مكتب المربي منفصلة عن معرض حتى خمسين طلبًا محفوظًا يدويًا، حتى لا يتوقف اللعب عند امتلاء المعرض. فتح محاولة سابقة ينشئ نسخة مستقلة. JSON الأعمال يستبعد هوية الحساب وملاحظات المربي وسجل المحاولات التلقائي؛ تصدير الأنماط مستقل. الطباعة تعرض الطلب وتمثيل الطفل وتجربة الطاولة.

التخزين المرفوض يعلن أن الحفظ مؤقت ويبقي التصدير متاحًا. الحفظ التالف يبقى دون استبدال حتى تنزيله خامًا واختيار المربي بدء حفظ جديد.

حزمة Offline تضم **407 موردًا** بما فيها الصور والأصوات الأصلية المشار إليها. تُعلن الجاهزية بعد اكتمال الكاش. يحفظ التحديث المسودة قبل إعادة التحميل. التثبيت الأول يحتاج شبكة ودعم Service Worker؛ الممارسة الأساسية لا تتطلبه.

## التشغيل والبناء

قدّم جذر المستودع بخادم ثابت:

```sh
python -m http.server 8080
node --test apps/4-8/family-market-lab/test/*.test.cjs
python apps/4-8/family-market-lab/tools/build_resources.py
python apps/4-8/family-market-lab/tools/build_content.py
python apps/4-8/family-market-lab/tools/build_offline.py
```

لبناء الصوت المؤلف فقط تحتاج `edge-tts` و`ffmpeg` وشبكة أثناء البناء:

```sh
python apps/4-8/family-market-lab/tools/build_audio.py /tmp/market-authored-audio-cache
```

الملفات الأصلية للأشياء والأعداد لا تُولد مجددًا. القراءة وقت الاستخدام تعتمد على الملفات المحلية. مثال رابط متنوع: `launch.html?experience=count&market=animals`؛ رابط قديم: `launch.html?item=ar-little-order`. يُرسل الإكمال عند الحفظ الفعلي.
