# سوق العائلة: أعدّ وأقسم وأوازن

تطبيق مستقل يعمل في فرع المعاينة `family-school-360-preview`، داخل بوابة مدرسة العائلة 360 أو من `index.html`. الحالة **معاينة تقنية**؛ التجربة الأسرية ومراجعة الصوت على الأجهزة المستهدفة لم تكتمل بعد.

يأخذ الطفل بطاقة طلب، ويحرك بطاقات الأشياء إلى السلال، ثم يعدّ أو يطابق ويفسر طريقته. تُحسب الكميات من البطاقات الفعلية، وتُحفظ المحاولات الأصلية قبل المساعدة أو المراجعة؛ فتح محاولة سابقة ينشئ نسخة مستقلة.

| المسار المرن | العمر الإرشادي | الممارسة |
| --- | --- | --- |
| أعدّ وأطابق | 4–5 | عدّ صغير، مطابقة، مقارنة الكمية، نمط AB |
| أكمل وأقسّم | 5–6 | إكمال طلب ناقص، تفكيك عدد، توزيع متساوٍ |
| أجمع وأوازن | 6–7 | جمع مجموعتين، إعادة الزيادة، طلب مختلط، توزيع |
| أفسّر وأصمّم | 7–8 | ثلاث سلال، نمط AAB، قياس بوحدات متساوية، دور البائع |

لكل لغة 16 مهمة، أربع لكل مسار، بنصوص عربية وإنجليزية مستقلة. يستطيع الطفل والمرافق تبديل المستوى دون بوابة درجات. مصمم الطلبات ينشئ كمية أو توزيعًا أو تقسيمًا أو نمطًا أو مقارنة، مع التحقق من حدودها، ويمكن للمرافق حفظ قوالب محلية.

## الصوت وتتبع الكلمات

- 173 ملف MP3 للمحتوى المؤلف، مع حدود الكلمات الفعلية ومدة كل مقطع في `data/read-along.json`. أرقام الطلبات والعد تُنطق بالإنجليزية في اللغتين.
- حزمة مشتركة محدودة من 12 صورة و24 تسجيلًا لأسماء الأشياء، رُقّيت دون تغيير بايتات موارد التطبيق السابق؛ المصدر والبصمات موثقان في `resources/early-child-market-objects`.
- خيار **تتبع الكلمات أثناء القراءة** في اللعب ومكتب المرافق يستخدم إعداد الأسرة المشترك. الأب أو المربي أو المساعد المخول يحدد الجميع أو متعلمًا محددًا؛ الضيف يتبع الاختيار. إيقاف التظليل يبقي الصوت يعمل.
- النص الجديد يُقرأ فقط بصوت محلي مناسب على الجهاز. تُفصل العربية والإنجليزية، وتُتجاوز علامات الترقيم، ويُصحح نطق اسم عُمَر. التتبع يتبع أحداث النطق؛ عند غياب الصوت المحلي يستمر الحكي واللعب، وتستخدم تعليمات الطلب المصمم بديلًا مسجلًا مع العدد واسم الصورة.
- لا يحتاج النشاط ميكروفونًا، ولا يُرسل نص الطفل إلى خدمة نطق خارجية.

## الحفظ والعمل دون اتصال

الحفظ محلي لكل ملف أسري مستقل تحت `app360:a4-family-market:schema-1:<profile>`، مع تراجع وإعادة ومسودة ومعرض حتى 50 طلبًا. تشمل نسخة JSON الطلب والمحاولة والتفسير، وتستبعد هوية الحساب وملاحظات المرافق الخاصة. الاستيراد محدود بالحجم والمخطط والكميات. الطباعة تحفظ بطاقة الطلب وتمثيل الطفل وتعليمات التجربة على الطاولة.

عند رفض التخزين يظهر أن الحفظ مؤقت ويظل التصدير متاحًا. الحفظ التالف لا يُستبدل أثناء اللعب أو تبديل الملف؛ يمكن تنزيله خامًا ثم بدء حفظ جديد باختيار المرافق.

تعلن حزمة Offline الجاهزية بعد تخزين 258 موردًا أساسيًا، تشمل كل صور الحزمة وأصواتها. يحفظ التحديث المسودة قبل إعادة التحميل. يحتاج التثبيت الأول شبكة ومتصفحًا يدعم Service Worker؛ غياب هذه الإمكانية لا يمنع الممارسة الأساسية.

## التشغيل والتحقق

قدّم جذر المستودع بخادم ثابت؛ لا تفتح التطبيق عبر `file://`:

```sh
python -m http.server 8080
node --test apps/4-8/family-market-lab/test/model.test.cjs
python apps/4-8/family-market-lab/tools/build_offline.py
```

إعادة بناء الصوت للمحتوى المؤلف فقط تحتاج Python وحزمة `edge-tts` و`ffmpeg` وشبكة أثناء البناء:

```sh
python apps/4-8/family-market-lab/tools/build_audio.py /tmp/market-authored-audio-cache
```

الوقت الفعلي وحدود الكلمات يعادان من مخرجات النطق، ولا تُنسخ توقيتات لغة إلى أخرى. وقت الاستخدام يعتمد على الملفات المحلية، ولا يشغل خدمة البناء.

الرابط `launch.html?item=ar-little-order` يفتح المهمة عبر عقد روابط App360، ويسجل الإكمال عند حفظ الطلب. الأزرار توفر بديلًا لكل عملية سحب، والمسار الأساسي ES5 مع Flexbox وأهداف لمس كبيرة.
