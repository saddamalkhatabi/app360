# مهامي باختياري: أبدأ وأنهي وأراجع

نسخة معاينة مستقلة للفئة 4–8. افتح `index.html` أو `launch.html` عبر HTTP.

الحفظ محلي حسب هوية APP360_SESSION، والضيف مساحة واحدة لهذا المتصفح. تصدير واستيراد لنفس التطبيق والهوية، حذف وطباعة من نموذج النشاط. لا رفع تلقائي.

ES5 وFlexbox وأزرار 48px. الحلقة الأساسية وأصول SVG مخزنة عبر SW مستقل. التوافق الفعلي مع Big TAB والتجربة الأسرية لم يختبرا على الجهاز الحقيقي بعد.

الصوت الحالي نطق الجهاز بالعربية مع تتبع كلمات عند أحداث boundary فقط؛ لا توقيت وهمي. تسجيلات SILMA المخصصة لم تُولد في هذه النسخة.

## النموذج الإبداعي

هدف وأدوات وخطة، ثم مفاجأة تجعل الطفل يصنع بديلًا يجربه في الواقع.

يظهر زر بدء النموذج في أول شاشة. حالة النموذج تحفظ ضمن مساحة الطفل نفسها. يمكن العودة للأنشطة الأصلية؛ هذا نموذج واحد صغير للتوسعة بعد مراجعة المستخدم.
