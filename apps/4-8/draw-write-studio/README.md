# مرسم المعنى: أرسم وأكتب رسالة

تطبيق عامل في فرع المعاينة `family-school-360-preview` ضمن مدرسة العائلة 360. مدخله `index.html`، ويُفتح أيضًا من البوابة والجلسة العائلية. البناء يطوّر تجربة الرسم في الفئة 1–4 إلى رسالة لها معنى ومتلقي، ويستخدم قراءة الكلمات المشتركة مع «حكاية وكلمة».

## تجربة المتعلم

| المستوى | العمر الاسترشادي | الناتج |
| --- | --- | --- |
| أرسم وأحكي | 4–5 | رسمة وحكاية يمليها الطفل أو يسجلها |
| صورة وكلمة | 5–6 | اسم أو كلمة في بطاقة أو لافتة |
| عبارة وبطاقة | 6–7 | دعوة أو رسالة لطيفة أو طلب مساعدة |
| رسالة وقصة | 7–8 | رسالة بسبب واضح، أو قصة من صفحتين |

المستويات كلها متاحة؛ يختار المرافق حسب الاستعداد، ولا يُمنع الطفل بسبب العمر. توجد 12 مهمة بالعربية و12 مهمة إنجليزية مستقلة، مع 196 ملفًا صوتيًا للتعليمات والأمثلة والكلمات ودليل المراحل.

- رسم حر، ألوان وسماكات، ممحاة، تراجع وإعادة، وأختام أصلية مرسومة بالكود.
- لوحة تدريب اختيارية منفصلة لحركة اليد أو كلمة عربية متصلة/إنجليزية؛ لا تستبدل رسم الطفل.
- كلمة أو عبارة اختيارية، إملاء على المرافق، وتسجيل محلي اختياري حتى 45 ثانية.
- معاينة ومتلقي وتفكير في معنى الرسالة، ثم حفظ نسخة أو طباعة أو تصدير صورة PNG.
- معرض خاص بالملف المحلي، نسخ للتحرير، وحفظ محاولات أصلية عند نقاط التحول، حتى 8 محاولات للمشروع و60 مشروعًا محفوظًا.
- مكتب المرافق: مقدار المساعدة، ملاحظات خاصة، ونسخ قوالب محلية قابلة للتعديل.

## القراءة والمزامنة

خيار «تركيز الكلمات» داخل التطبيق يستخدم API القراءة نفسه في المزامنة العائلية. يستطيع المرافق المحلي، أو الأب/المربي/المسؤول المساعد المصرّح له في الجلسة، تشغيل التظليل أو إيقافه. إعداد الجلسة يدعم الجميع واستثناء كل متعلم. المتعلم الضيف يرى الحالة ولا يتجاوز سلطة المرافق. إيقاف التظليل أثناء الاستماع لا يوقف الملف الصوتي.

توقيت الكلمات المسجلة مأخوذ من `WordBoundary` في عملية إنتاج الصوت نفسها؛ لا مؤقت تقديري. النص الذي يكتبه الطفل يُقرأ فقط بواسطة صوت يعلن المتصفح أنه محلي (`localService=true`) باللغة المناسبة. إن لم يتوفر، تظهر رسالة واضحة ويظل التسجيل والحكي والكتابة متاحًا. الأرقام والمقاطع اللاتينية تُقرأ بالإنجليزية، مع تصحيح نطق أسماء عربية شائعة منها «عُمَر». جودة نطق النص الجديد تعتمد على محرك الجهاز.

## الحفظ والخصوصية والتثبيت

الرسوم والنصوص والملاحظات تحفظ في `localStorage` بالمفتاح `app360:a4-draw-write:schema-1:<profile>`، والتسجيلات في IndexedDB على الجهاز. التطبيق لا يرفع رسومات الطفل أو نصه أو تسجيلاته. ملف JSON الافتراضي يستبعد هوية الحساب وملاحظات المرافق والتسجيلات، لكنه يحتوي النصوص والرسوم التي يختار المستخدم تصديرها. لا تنقل التسجيلات تلقائيًا بين الأجهزة أو عبر المزامنة؛ المزامنة هنا تدير الفتح وإعداد القراءة المشترك.

عند منع التخزين يُتاح العمل مؤقتًا مع تنبيه للتصدير. الملف التالف لا يُستبدل تلقائيًا؛ يمكن تنزيل نسخة خام قبل إعادة الحفظ. الاستيراد يتحقق من المخطط والإحداثيات والحدود قبل تعديل المعرض. إغلاق المتصفح بالقوة أثناء التسجيل لا يضمن حفظه؛ أوقف التسجيل أولًا. انتقالات التطبيق وتحديثه تنتظر اكتمال حفظ التسجيل.

الحزمة الأساسية تضم الرسم والمحتوى والصوت. لا تظهر جاهزية العمل دون اتصال إلا بعد اكتمال تثبيت 245 موردًا. التحميل الأول يحتاج اتصالًا، وإمكانات Service Worker والتسجيل تعتمد على المتصفح وHTTPS. على المتصفحات القديمة تبقى تجربة الرسم والنص والحفظ مع بدائل للميزات غير المتاحة.

## التطوير والتحقق

```sh
node --test apps/4-8/draw-write-studio/test/model.test.cjs
python3 apps/4-8/draw-write-studio/tools/build_offline.py
```

ملفات المحتوى المنفذة هي `data/content.json` ونسخته `data/content.js`، والصوت في `data/audio-manifest.json`، وتوقيت الكلمات في `data/read-along.json`. بعد تعديل مادة صوتية أعد إنتاج الصوت وتوقيته معًا. أداة البناء تحتاج `edge-tts` وFFmpeg:

```sh
python3 apps/4-8/draw-write-studio/tools/build_audio.py /tmp/studio-speech-cache
```

هذه الأداة ترسل مادة المنهج المؤلفة فقط وقت البناء، وليست جزءًا من تشغيل التطبيق ولا تقرأ بيانات الطفل. الرسوم والأختام محلية ومنشأة بالكود. راجع [تقرير التحقق](VALIDATION_AR.md)، [مواصفات البناء](BUILD_SPEC.md)، و[بذور المحتوى](CONTENT_SEEDS.json). مواصفات الكتالوج المشتقة تُجدد من `data/catalog.json` بواسطة `tooling/build-blueprints-active.js`.

الحالة الحالية: معاينة تقنية ناجحة؛ تجربة أسرية ومراجعة سمعية بشرية للعربية والإنجليزية، وفحص جهاز Big TAB فعلي، مطلوبة قبل وصفه بإصدار نهائي. هذا العمل لا ينشر على Railway ولا يغير `main`.
