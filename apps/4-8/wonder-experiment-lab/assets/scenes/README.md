# مشاهد التجارب

ست صور JPEG بدقة 1024×1024؛ كل صورة تحتوي أربعة مشاهد بدقة 512×512 مرتبة: أعلى يسار، أعلى يمين، أسفل يسار، أسفل يمين. الواجهة تعرض المشاهد بالتتابع أو جميعها، بأزرار كبيرة وصوت عربي/إنجليزي وتتبع الكلمات من التسجيل الأصلي. الصور مصممة باستخدام builtin imagegen بأسلوب فوتوغرافي، وليست تصويرًا لتجارب حقيقية. عدد المكعبات والأوراق في الصور أمثلة توضيحية ثابتة؛ تبقى نتائج النموذج المتنوعة ودفتر الملاحظة مستقلة.

تحتوي الحزمة المضغوطة على هذه الملفات نفسها. الملفات مفكوكة مسبقًا في هذا المجلد ليعمل التطبيق مباشرة؛ GitHub لا يفك ZIP تلقائيًا. لا يحتاج تشغيل التطبيق إلى تحميل الحزمة المضغوطة أو تثبيت أدوات. المصادر الأصلية غير المضغوطة خارج المستودع.

`manifest.json` يسجل الحجم والبصمة لكل صورة، و`prompts.json` يوثق التصميم. يمكن إعادة التحويل باستخدام `tools/build-scenes.cjs` مع خريطة مسارات الصور الأصلية وSharp في بيئة البناء فقط. القص يزيل ست بكسلات من حواف كل مقطع لإزالة فواصل الشبكة، ثم يركب المقاطع في شبكة نظيفة ويحفظ JPEG بجودة 82.
