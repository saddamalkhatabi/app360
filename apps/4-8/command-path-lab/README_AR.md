# مسار الأوامر: أخطط وأصحح

نسخة تقنية للتجربة العائلية في مجموعة 4–8. ثلاثة مسارات استعداد قابلة للاختيار، و12 خريطة لكل مسار. الأعمار إرشادية، ولا يوجد ترتيب تنافسي أو مؤقت أو اشتراط قراءة.

- أرتب الطريق: أسهم ثابتة بالنسبة للخريطة، وتوقع بالإشارة.
- أدور وأصحح: تقدم بالنسبة لاتجاه الروبوت ودوران في المكان، وتعديل بطاقة محددة.
- أكرر وأبتكر: مجموعة تكرار من آخر بطاقتين، وفحص مرئي: إذا كان أمام الروبوت حاجز أو حافة يدور يميناً، وإلا يتقدم.

أزرار كبيرة بديل للسحب، تنفيذ خطوة بخطوة أو تشغيل قابل للإيقاف، مقارنة الطريق المتوقع بالمشاهد، حفظ محاولات مستقلة وإعادة فتح نسخة، ومصمم لغز يفحص إمكان الوصول قبل الحفظ دون كشف الحل. طباعة البطاقات والطريق من نفس النموذج، وتصدير واستيراد JSON مع نسخة نصية بديلة للتنزيل. ملاحظات المربي الخاصة وهوية المستخدم لا تدخل التصدير المعتاد.

الواجهة عربية وإنجليزية. 68 تسجيلًا مولدًا باستخدام أصوات Microsoft Edge عبر tooling/build-authored-audio.py، مع WordBoundary من التسجيل الفعلي للمتابعة القرائية المشتركة. ست صور مقاصد مرجعية من resources/early-child-market-objects، دون نسخ الصور أو استيراد كود تطبيق حي. الروبوت والحواجز والأسهم SVG مستقل. المقاصد المسموحة كتاب وكرة وتفاح ودب وقطة وسيارة. لا يتصل التطبيق بمولد محتوى أو نموذج ذكاء اصطناعي أثناء الاستخدام.

الحفظ منفصل حسب ملف العائلة من API المنصة، مع وضع ذاكرة مؤقتة عند رفض التخزين، والحفاظ على النص الأصلي إذا كان تالفًا. دور الضيف لا يغير إعداد المربي أو ملاحظاته. العمل دون اتصال متاح في المتصفحات التي تدعم Service Worker، بعد اكتمال تحميل الحزمة مرة؛ الأجهزة القديمة تعمل بالواجهة الأساسية على اتصال وتحتاج التصدير إذا منع المتصفح حفظها.

حدود التطبيق: تنفيذ رقمي حتمي للأوامر، ولا يحكم على نمو الطفل أو قدرته. برنامج فيه أمر حاجز يتوقف عند أول حاجز؛ الوصول يحسب عند نهاية البرنامج، وليس مجرد المرور بالمقصد. الاتجاهات لا تنعكس بتغيير لغة الواجهة. الحد 32 بطاقة و80 خطوة موسعة، 50 طريقاً محفوظاً، 30 لغزاً، و12 محاولة حديثة. لا تكرار متداخل. البطاقات الورقية تستخدم على طاولة أو في مساحة آمنة بإشراف المرافق.

## إعادة الفحص

`node apps/4-8/command-path-lab/tools/test-model.cjs`

فحص المتصفح يستخدم Playwright المثبت في CODEX_PRIMARY_RUNTIME_NODE_MODULES وChromium من CHROMIUM_PATH إذا حدد. الأمر من جذر المستودع:

`CHROMIUM_PATH=/path/to/chromium node apps/4-8/command-path-lab/tools/test-browser.cjs`

لتوليد المحتوى المحلي: `node apps/4-8/command-path-lab/tools/build-content.cjs`. ثم توليد التسجيلات باستخدام أداة الصوت المشتركة أعلاه. هذه عملية بناء وليست اتصالًا عند استخدام الطفل للتطبيق.

راجع QA_AR.md لنتائج الفحص وحدوده. النشر على family-school-360-preview فقط؛ main وRailway خارج نطاق هذه النسخة.
