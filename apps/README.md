# التطبيقات الفردية في مختبر التطبيق 360

هذا المجلد هو **المكان القياسي من الآن فصاعدًا** لكل تطبيق جديد مستقل.

المسار:

```text
apps/<age-group>/<app-slug>/
```

مثال:

```text
apps/8-12/stem-code-maker/
```

كل تطبيق مستقل يجب أن يحتوي على الأقل `index.html` و`app.json` و`README.md`، ثم يضاف سجل واحد له إلى `data/catalog.json`.

## مهم

المجلد التاريخي `/1-4/` يحتوي التطبيق العامل الحالي للرسم والكتابة وصوته وتوافقه القديم. **لا تنقله أو تعيد هيكلته أثناء تطوير تطبيق آخر.** نقله لاحقًا يحتاج مهمة مستقلة وخطة ترحيل مع الحفاظ على الروابط والكاش والصوت.

لبدء تطبيق جديد انسخ البنية المفاهيمية من `_template/` واقرأ `../docs/APP_SPEC_TEMPLATE_AR.md` و`../docs/FRAMEWORK_AR.md`.
