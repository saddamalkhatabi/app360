# اسم التطبيق

> قالب بداية لتطبيق مستقل في مختبر التطبيق 360. استبدل كل النصوص المؤقتة قبل بدء التطوير.

## البطاقة

- الفئة العمرية: `8-12`
- الحالة: `planned`
- النوع: `goal_aligned`
- مسار الدخول: `apps/8-12/<slug>/index.html`
- الأهداف المرتبطة: أضف `goal_keys` الدقيقة من `data/goals.json`.

## النتيجة العملية المستهدفة

صف ما سيتمكن المستخدم من **فعله** بعد التدريب، وليس فقط ما سيعرفه.

## حلقة الممارسة

`مهمة ← محاولة ← تغذية راجعة ← تصحيح ← تكرار/تدرج`

## نطاق MVP

- الشاشة/المهمة الأولى.
- الممارسة الأساسية.
- التغذية الراجعة.
- التدرج الضروري فقط.
- حفظ محلي عند الحاجة.

## خارج النطاق حاليًا

اكتب ما لن يتم بناؤه في هذه النسخة لتجنب تمدد المهمة في محادثة مستقلة.

## التوافق

حدد الهاتف/التابلت/الحاسوب، وهل دعم Android قديم مطلوب أم لا.

## الصوت والوسائط

حدد TTS أو الملفات المسجلة أو fallback بصري، إن احتاج التطبيق.

## الخصوصية

حدد أي بيانات تخزن محليًا أو ترسل لخدمة خارجية، وإن لم توجد فاكتب ذلك صراحةً.
