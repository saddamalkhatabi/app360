# دوري ودورك: قلّد حركة واحدة

نسخة أولى قابلة للتجربة لتطبيق `a1-imitate` ضمم مختبر التطبيق 360 للفئة `1-4`.

## النتيجة العملية

محاولة قصيرة لتبادل الدور بين الطفل والمرافق باستخدام لعبة حقيقية: يعرض المرافق حركة واحدة، تُخفى الشاشة، يقلد الطفل الحررة مع تسجيل مقدار المساعدة، ثم يبدأ الطفل يقود ← دورك ← تسجيل المساعدة ← الطفل يقود ← حفظ/تصدير`

يوجد 8 بطاقات برسوم SVG أصلية داخل التطبيق، منها المكعب والسلة، دحرجة الكرة، دفع السيارة، وتكديس مكعبين.

## فصل دور المتعلم عن المرافق

- **الطفل:** اللعب الحقيقي والانتباه والتقليد والمبادرة؛ لا يحتاج إلى قراءة أو لمس دقيق.
- **المرافق:** يستخدم الشاشة، يعرض النموذج، يصف الحركة مرة واحدة، ينتظر، ويسجل مقدار المساعدة.
- إكمال الحلقة يتطلب تبادل الدورين؛ لا يكفي تسجيل محاولة الطفل وحدها.

## البيانات والخصوصية

- لا حسابات، لا شبكة، لا خدمات خارجية، ولا مفاتيح API.
- يخزن محليًا: `session_id`, `task_id`, `attempts`, `artifact`, `reflection`, `assistance_level`.
- يحتفظ بآخر 30 جلسة، مع تصدير JSON وحذف السجل.
- إذا رفض المتصفح التخزين، تستمر الممارسة بذاكرة مؤقتة ويظهر تحذير مع خيار التصدير.

## PWA وOffline

التطبيق `offline-first` بعد أول فتح ناجح. له Manifest وService Worker ونطاق مستقل وأيقونات خاصة. التنقل يستخدم network-first، بينما أصول الممارسة cached-first. التحديث يستخدم helper المنصة مع `updateViaCache: none` و`SKIP_WAITING` من دون حلقة refresh متعمدة.

## الاختبارات المنفذة آليًا في النسخة الأولى

شغّل من مجلد التطبيق:

```bash
node --test practice-core.test.js
```

وتغطي الاختبارات: إنشاء الجلسة، تسجيل المساعدة، إعادة النموذج، إكمال تبادل الدور، الحفظ/الاستعادة/التصدير/الحذف، ورفض التخزين مع fallback.

## ما يزال مطلوبًا قبل `live`

- تجربة ممارسة فعلية مع طفل ومرافق مناسبين للفئة ومراجعة وضوح البطاقات وطول الحلقة.
- اختبار يدوي على هاتف حديث وتابلت Android حديث وحاسوب، رأسيًا وأفقيًا.
- اختبار تثبيت PWA وانقطاع الشبكة وتحديث Service Worker فعليًا في متصفح حقيقي.
- لا ندعي دعم Android القديم في هذه النسخة قبل اختباره.
