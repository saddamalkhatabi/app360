# دوري ودورك

## الواجهة الحالية

التطبيق يحتوي 200 تجربة، لكن التجربة نفسها أصبحت بسيطة جدًا:

1. عنوان ورقم التجربة وفكرتها.
2. Storyboard واحد من خمس لقطات يتحرك تلقائيًا لقطة بعد لقطة مثل فيديو قصير، مع تشغيل/إيقاف/إعادة.
3. الأدوات أو البدائل فقط.
4. زر **تم عمل التجربة** يزيد عداد التنفيذ المحلي.
5. ملاحظة تحسين اختيارية تحفظ على الجهاز.
6. قسم تعليقات المجتمع العامة.

شرح طريقة اللعب (شاهد ← نفذ ← دع الطفل يجرب ← بدّل القيادة ← سجل التحسين) يظهر مرة واحدة فقط أسفل التطبيق، وليس داخل كل تجربة.

## الصور

كل Storyboard صورة واحدة بخمس لوحات أفقية متساوية، ويعرض التطبيق لوحة واحدة في كل لحظة وينقل الصورة تلقائيًا حتى اللوحة الخامسة.

## التعليقات العامة

القناة العامة الحالية هي GitHub Issue #8. التعليقات تبدأ بالوسم `[EXP:NNN]` ويعرض التطبيق التعليقات الخاصة بكل تجربة. قراءة التعليقات عامة. النشر يتطلب تسجيل دخول GitHub، والتطبيق ينسخ التعليق الموسوم ويفتح خانة النشر. لا توجد مفاتيح API أو أسرار في الواجهة.

## الخصوصية

عداد التنفيذ والملاحظات الشخصية محلية. لا تضع بيانات شخصية للأطفال في التعليقات العامة.
