# دوري ودورك

نسخة Alpha موسعة للتطبيق `a1-imitate`.

## النسخة الحالية

- 200 تجربة.
- 4 مستويات متدرجة و10 مجالات.
- بحث وفلاتر حسب المستوى والمجال والأدوات والطاقة والمكان.
- عرض تدريجي 24 بطاقة للحفاظ على سرعة الواجهة.
- لكل تجربة أدوات وبدائل ومدة ومكان وطاقة وخمس خطوات ونسخة أسهل وأصعب وسلامة.
- مؤقت وإشارة ابدأ/انتظر/توقف وصبورة مشتركة.
- حلقة ممارسة: جهّز ← دوري ← دور الطفل ← بدّل القيادة ← طوّر الجولة.
- حفظ محلي وتصدير JSON وحذف.
- PWA Offline-first.

## الصور

`storyboards/<ID>.webp`، صورة واحدة لكل تجربة بخمس لقطات ثابتة. عند عدم وجود الصورة يظهر بديل رمزي كامل.

## الاختبار

`npm run validate` يفحص Syntax، عدد التجارب، توزيع المستويات والمجالات، بنية كل تجربة، محرك الفلاتر ونواة الحفظ.

الحالة ما تزال Alpha وليست live حتى اختبار الممارسة والأجهزة فعليًا.
