# Storyboards

- الصيغة المفضلة: `WEBP`.
- العقد الحالي للعرض: صورة أفقية واحدة بقياس `4500x900`، تتكون من خمس لقطات مربعة متساوية `900x900`.
- ترتيب اللقطات: جهّز ← دوري ← دورك ← بدّل ← طوّر.
- بعد رفع الصورة أضف مسارها إلى `manifest.json`، مثل: `"001": "storyboards/batch1/001.webp"`.
- عند عدم وجود الصورة يعرض التطبيق البديل الرمزي تلقائيًا.
- يجب أن توضح الصور أدوات كبيرة وآمنة ومناسبة للفئة العمرية، وأن تطابق التجربة نفسها بدقة.

## Batch 1

تم استخراج الملف `imitate_one_step_storyboards_batch1_webp_only.zip` آليًا إلى:

`storyboards/batch1/001.webp` … `storyboards/batch1/010.webp`

وتم توحيد كل ملف إلى `4500x900` بخمس لقطات متساوية. التجربة `001` فقط مفعلة حاليًا من هذه الدفعة لأنها تطابق محتوى التجربة الفعلي. الصور `002` إلى `010` محفوظة في staging داخل نفس المجلد، ولا تُربط بالمحتوى الحي إلا بعد إعادة توليدها أو مطابقتها مع عناوين التجارب الصحيحة.
