# Storyboards

- اسم الملف: `<ID>.webp` مثل `001.webp`.
- المقاس الموصى به: `1600x900`.
- صورة واحدة لكل تجربة تحتوي خمس لقطات: جهّز ← دوري ← دورك ← بدّل ← طوّر.
- بعد رفع الصورة أضفها إلى `manifest.json`: `"001": "storyboards/001.webp"`.
- عند عدم وجود الصورة يعرض التطبيق البديل الرمزي تلقائيًا.
- يجب أن توضح الصور أدوات كبيرة وآمنة ومناسبة للفئة.
