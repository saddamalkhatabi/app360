# مطالبة صيانة التطبيق

اعمل داخل `apps/1-4/tangram-builder/` فقط عند تعديل تجربة التانغرام، واقرأ أولًا وثائق إطار المشروع وسياسة الاعتماد وPWA. حافظ على هوية التطبيق `a1-tangram` ومسار `tangram-builder`.

القواعد الثابتة:
- الفئة الرسمية 1–4 مع استخدام مشترك مع المرافق.
- ثلاث مستويات متدرجة وتسع جولات على الأقل في النسخة الحالية.
- التفاعل الأساسي ES5 + Canvas + Touch Events مع mouse fallback، ولا تجعل Pointer Events أو CSS Grid أو مكتبة خارجية شرطًا.
- snap سخي ومباشر؛ لا تدوير إلزامي ولا لمس دقيق.
- لا نقاط عقابية ولا مؤقتات ولا تصنيف للذكاء أو النمو.
- الخطأ محايد؛ لا تستخدم التسجيلات الصوتية التشجيعية إلا بعد اكتمال الجولة.
- التشجيع بالاسم يستهلك المورد المشترك `resources/early-child-name-audio/` ولا ينسخ ملفات الصوت إلى التطبيق.
- أبق اللعبة صالحة بصريًا بالكامل إذا فشل الصوت أو التخزين.
- اختبر التاب Android 4.4.2 فعليًا قبل الادعاء بإغلاق توافقه نهائيًا.
