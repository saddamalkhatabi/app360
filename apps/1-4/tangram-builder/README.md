# تانغرامي الصغير: ابنِ الشكل

تطبيق أصلي ضمن مختبر التطبيق 360 للفئة 1–4، مستلهم من **فكرة** ألعاب تركيب الأشكال الهندسية بالسحب والإفلات دون نسخ رسومات أو أصول أو هوية أي تطبيق مرجعي.

## التجربة
- 3 مستويات متدرجة و9 أشكال قابلة للبناء.
- السحب واللمس مباشر، والقطعة تلتقط بمنطقة لمس أكبر من حدودها المرئية.
- لا تدوير للقطعة في النسخة المبكرة؛ المهمة هي المطابقة والمكان لا التحكم المعقد.
- إسقاط قريب من الهدف يلتقط القطعة تلقائيًا بحد تسامح مناسب للمستوى.
- الخطأ يعيد القطعة بهدوء من دون عقوبة أو صوت تشجيع مسجل.
- الفوز فقط يشغل المفرقعات والتشجيع الصوتي بالاسم.

## التوافق
المحرك مكتوب ES5 ويعتمد Canvas 2D وTouch Events مع mouse fallback. لا يعتمد Pointer Events أو CSS Grid أو مكتبة سحب خارجية في المسار الأساسي، لذلك يبقى مناسبًا لمسار اختبار Android 4.4 القديم إلى جانب المتصفحات الحديثة.

## الصوت المشترك
يستهلك التطبيق المورد المشترك `resources/early-child-name-audio/` الذي رُقّي من حزمة لوحة الرسم عند ظهور هذا المستهلك الثاني. الأولوية: ملف مسجل بالاسم، ثم PCM/صوت الجهاز، ثم نغمة بسيطة. مفاتيح الاسم البسيطة متوافقة مع لوحة الرسم.

## حدود الاستخدام
هذه لعبة ممارسة بصرية وحركية وليست اختبار ذكاء أو أداة تقييم نمائي. المستويات تصف تعقيد الجولة فقط ولا تصنف قدرات الطفل.
