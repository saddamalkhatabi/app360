# حديقة البالونات · مزرعتي تنمو — v2

4 مستويات × 3 حقول لكل فئة عمرية، مع تقدم مستقل للأطفال والفئتين. كل زهرة تمر بزرع البذرة ثم الماء ثم ضوء الشمس، وبينها اكتشاف لون أو عدد أو حرف أو صورة كلمة. احفظ الهدية قبل استخدامها ثم استكملها بعد الإغلاق. عرض المزرعة الكبيرة يجمع الحقول؛ يمكن العودة لأي حقل دون مسح نموه.

- الصور والتسجيلات مرجعيات إلى التطبيقات الحالية؛ لا نسخ لأصولها.
- موارد اللعبة الجديدة SVG/CSS/ES5، بلا WebGL أو خدمات خارجية.
- تسجيل توجيهات المزرعة كاملة والحروف الإنجليزية مرحلة لاحقة؛ الأعداد الحالية بتسجيل إنجليزي.
- `node tooling/build-balloon-content.cjs` لتجديد المراجع من المكتبات الحالية.
- `node tooling/build-public-links.js && node tooling/build-balloon-garden-offline.cjs` لتجديد الروابط وحزم التنزيل بعد تعديل ملفاتها.
- `node --test apps/1-4/balloon-garden/tests/*.test.cjs` لفحص النمو والمراجع والتقاعد والعامل.
- `NODE_PATH=<QA modules> APP360_TEST_CHROMIUM=<browser> node apps/1-4/balloon-garden/tests/browser.cjs` للفحص المرئي والعمل الفعلي دون اتصال.

لا درجات إتقان أو مقارنة بين الأطفال. اختبار الجهاز القديم الفعلي والاستماع البشري للتسجيلات مطلوبان أثناء التجربة الأسرية.
