# ألعاب إبداعية عبر الشاشة — أو بدون الشاشة

هوية التطبيق: `a1-screen-move`  
المسار الرسمي: `apps/1-4/screen-to-move/`  
الإصدار الحالي: `v3` — مفعّل في مختبر التطبيق 360.

## التجربة الحالية

التطبيق يضم **20 لعبة أصلية** موزعة بالتساوي على **4 درجات استعداد**. يبدأ من اللمس والمطابقة البسيطة مع المرافق، ثم يتدرج إلى التوصيل والفرز والذاكرة والأنماط والنقاط والمسارات والبازل والاستدلال والابتكار المشترك.

التدرج تقريبي وبحسب استعداد الطفل لا العمر وحده:
- المستوى الأول: تقريبًا 1–2 سنة مع المرافق.
- المستوى الثاني: تقريبًا 2–3.5 سنة.
- المستوى الثالث: تقريبًا 3.5–5 سنوات.
- المستوى الرابع: امتداد اختياري مبسط تقريبًا 5–7 سنوات لمن أصبح مستعدًا.

يبقى تصنيف التطبيق الرسمي في المنصة ضمن الفئة `1-4`، ولا تمثل هذه الأعمار اختبارًا نمائيًا.

## عرض خطوات اللعبة

لكل لعبة **5 خطوات مصورة مستقلة**. لم يعد العرض يعتمد على شريط بعرض متعدد أو إزاحة نسبية؛ تعرض كل لقطة مباشرة داخل عنصر واحد، مع:
- السابق.
- التالي.
- تشغيل تلقائي يمكن إيقافه.
- العودة إلى البداية.
- صور مصغرة للخطوات الخمس.
- عرض الخطوات الخمس كلها في وقت واحد.

## اللعب المباشر على الشاشة

مسار الشاشة أصبح ممارسة فعلية وليس مجرد بديل بصري. المحرك يدعم الأنواع الموجودة حاليًا في المكتبة:
- اختيار صورة أو حل نمط.
- مطابقة زوجين.
- فرز قطع إلى مجموعات.
- ذاكرة البطاقات.
- ترتيب تسلسل مصور.
- بازل مبسط.
- توصيل نقاط ومسارات بالرسم.
- إكمال شكل بالرسم.
- ابتكار لغز وتبادل الدور.

تظهر أثناء الجولة:
- عدد المحاولات.
- عدد النجاحات.
- تقدم فكرة الجولة.
- تلميح اختياري.
- إعادة نفس الجولة.
- نتيجة ختامية وصفية مع نسبة التقدم ودقة المحاولات عندما ينطبق ذلك.

**النتيجة تصف الجولة داخل التطبيق فقط؛ لا تقيس ذكاء الطفل أو نموه ولا تدعي تقييم الأداء خارج الشاشة.**

## اللعب الورقي والواقعي

خيار اللعب بدون الشاشة باقٍ لكل لعبة، ويشمل:
- مواد اللعبة.
- ست أفكار واقعية بديلة مرتبطة بنوع النشاط.
- ورقة A4 قابلة للطباعة.
- تنزيل SVG.
- حزمة أوراق العمل.
- نهاية واضحة لا تطلب صورة أو إثباتًا لما حدث خارج الشاشة.

## الرسم المشترك

توجد لوحة رسم مشتركة مستقلة للطفل والمرافق، تدعم اللمس والفأرة والألوان والممحاة والتراجع والمسح وحفظ الصورة. زر الرجوع أو لمس الخلفية يغلق اللوحة بدل الخروج من التطبيق.

## الاسم والتشجيع الصوتي المشترك

يستخدم التطبيق نفس المفتاحين المحليين المستخدمين في **لوحة الطفل للرسم والكتابة المبكرة**:
- `pk_user_name`
- `pk_user_gender`

ولا توجد نسخة ثانية من مجلدات أسماء الأطفال. تم تطوير محرك الصوت في تطبيق الرسم ليقبل `Audio360Base`، ولذلك يقرأ هذا التطبيق مباشرة من:
`apps/1-4/drawing-writing-foundations/audio/`

ويستفيد من سجل الأسماء نفسه ومن ملفات MP3/OGG/WAV وFallback PCM/WebAudio للأجهزة القديمة، مع TTS كبديل عندما يلزم.

## الحفظ والخصوصية

المفتاح المحلي الحالي:
`app360:a1-screen-move:schema3`

يحفظ التطبيق اختياريًا نتيجة الجولة ومقدار المساعدة والملاحظة التي يكتبها المرافق، مع تصدير JSON وحذف السجل. إذا تعذر `localStorage` تستمر الممارسة دون ادعاء الحفظ.

لا توجد حسابات أو إرسال تلقائي أو كاميرا أو مراقبة للطفل خارج الشاشة.

## PWA والتوافق

التطبيق Offline-first بعد التحميل الأول، وله Manifest وService Worker وأيقونات مستقلة، مع زر تثبيت وفحص تحديث. أعلن العقد قدرات التوافق القديم والصوت المسجل وFallback الصوتي لأن التطبيق أصبح مستهلكًا ثانيًا لمكتبة الصوت نفسها.

التوافق البرمجي مصمم ليكون واسعًا، لكن اعتماد جهاز قديم بعينه يظل مرتبطًا بالاختبار الفعلي عليه.

## التحقق

داخل Workspace:
```bash
node tooling/build-blueprints.js
node tooling/validate-platform.js
pnpm --filter @app360/app-screen-to-move validate
```

اختبارات التطبيق تتحقق من:
- وجود 20 لعبة و4 مستويات × 5 ألعاب.
- وجود خمس خطوات ومواد لكل لعبة.
- تغطية جميع أنواع الألعاب بالمحرك المباشر.
- عدم رجوع عارض الخطوات إلى استراتيجية `500%`/`translate3d` القديمة.
- وجود نتيجة الجولة والتكامل مع مكتبة الصوت المشتركة.
- الاسم الجديد ومسار اللعب عبر الشاشة أو بدونها.

الحالة في الكتالوج والعقد: `live`. اختبار مصفوفة الأجهزة الفعلية الموسعة مستمر كقبول جهاز، وليس شرطًا لإظهار التطبيق في مختبر الفئة بعد طلب التفعيل من مالك المشروع.
