# كلماتي مع أشيائي: اسمع وأشر وسمِّ

تطبيق ممارسة لغوية محلي للفئة **1–4 سنوات** مع مرافق بالغ. يعرض 12 صورة أصلية لأشياء مألوفة، يختار المرافق ما هو موجود حول الطفل، يسمع الاسم أو يقوله بنفسه، ثم ينتقل النشاط إلى الشيء الحقيقي.

## ما بُني

- اختيار 3–12 أشياء من حزمة من 12 صورة أصلية داخل التطبيق.
- نطق عربي عبر Web Speech API عند توفر صوت عربي، مع fallback واضح للمرافق بدل تعطيل النشاط.
- مؤثرات صوتية محلية صغيرة تعمل Offline ولا تعتمد على الشبكة.
- تسجيل نوع الاستجابة: إشارة، تقليد، كلمة، طلب/استخدام، أو لا استجابة بعد.
- بطاقة للمرافق: اتبع اهتمام الطفل، انتظر، ثم وسّع استجابته بجملة قصيرة.
- سجل جلسات محلي وفق schema ثابت مع إعادة فتح، تصدير JSON/TXT، وحذف.
- عند رفض التخزين يستمر النشاط بذاكرة مؤقتة مع تنبيه وخيار تصدير.
- PWA مستقلة، Service Worker مع Offline shell، وأيقونات 192/512/SVG.

## حدود مقصودة

لا يوجد تشخيص، ولا درجة للنطق، ولا تعرف آلي على صوت الطفل، ولا رفع بيانات أو صوت إلى خادم. الإشارة وحدها استجابة صالحة لإكمال الموقف.

## حالة المراجعة الحالية

التنفيذ موجود ويعرضه المختبر ضمن التطبيقات المتاحة للمراجعة العملية. يبقى عقد التخطيط الأساسي متوافقًا مع دورة الاعتماد الداخلية إلى أن تكتمل مراجعة الأجهزة والممارسة، بينما تتولى طبقة حالة التشغيل إظهار زر الدخول للمستخدمين.

تم كذلك إصلاح طبقة تفاصيل السجل بحيث يحترم العنصر `hidden` ولا تظهر النافذة الفارغة فوق التطبيق عند الفتح.
