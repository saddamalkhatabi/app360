# كلماتي مع أشيائي: اسمع وأشر وسمِّ

النسخة v5 تعيد تصميم التطبيق كمكتبة معرفة مرئية وصوتية مصنفة للفئة 1–4 سنوات.

- عرض عام أو حسب التصنيف.
- التصنيفات: أشياء في المنزل، مخلوقات في الطبيعة، الحيوانات، الفواكه والطعام، وأدوات ومهن.
- 30 بطاقة، وكل بطاقة لها رسم SVG أصلي؛ الرسومات مجمعة داخل 5 ملفات SVG sprite في assets/sprites/ بواقع 6 صور لكل تصنيف.
- أسهم، سحب باللمس، لوحة مفاتيح، وشريط Range.
- تشغيل تلقائي بسرعات مختلفة مع نطاق حركة داخل التصنيف أو بين الجميع.
- تشغيل/إيقاف النطق العربي.
- ملء الشاشة للشاشات الكبيرة.
- إرشاد المرافق عنصر ثانوي مختصر.
- Offline-first.

لا ميكروفون، لا تسجيل لصوت الطفل، ولا درجات أو تشخيص.
