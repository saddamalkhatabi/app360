# كلماتي مع أشيائي: اسمع وأشر وسمِّ

- الفئة الأساسية: 1–4
- الهوية: `a1-first-words`
- المسار: `apps/1-4/say-and-name/`
- الحالة: **يعمل الآن**
- الإصدار التشغيلي: **19**

## الفكرة الحالية

تطبيق مفردات بصري وصوتي بأربعة مستويات تراكمية. يعرض صورة واضحة للمفهوم، ويسمح بالعربية أو English أو اللغتين معًا، مع اختيار مستقل للغة النطق، وتصنيفات منظمة، ومراجعة عشوائية، وتعليمات موجهة للمربي أو للطفل الواعي.

## الناتج العملي

استجابة تواصل ذات معنى: إشارة، اختيار، تقليد أو تسمية. لا توجد درجة تشخيصية للنطق ولا تسجيل صوت إلزامي.

## سيناريوهات الاستخدام

1. **طفل صغير مع مرافق:** اختر تصنيفًا مألوفًا، اطلب الإشارة أو التسمية قبل تشغيل الصوت، ثم اربط الصورة بشيء حقيقي إن أمكن.
2. **عربي + English:** اعرض الاسمين معًا واختر نطق اللغتين بالتتابع للمقارنة والتثبيت.
3. **تعلم English للفئات الأكبر:** اختر English للعرض والنطق واستخدم الصور والتصنيفات للمراجعة السريعة للمفردات والنطق. هذا ليس منهج قواعد أو محادثة كاملًا.
4. **مراجعة عشوائية:** استخدم «متنوع عشوائي 10» بعد التعلم لمراجعة كلمات من تصنيفات مختلفة.
5. **مربٍ أو معلم:** استخدم التعليمات والجولة المدمجة، وانتظر محاولة المتعلم قبل تشغيل الاسم ثم وسّع الاستجابة بكلمة أو جملة قصيرة.
6. **اتصال محدود:** بعد التحميل الأول تعمل الواجهة والصور وفق Offline-first عبر PWA، مع TTS احتياطي وفق قدرات الجهاز.

## الارتباط بالأهداف

### الكلمات الأولى واللغة التعبيرية
يعرض صورة واسمًا منطوقًا ثم يتيح الإشارة أو الاختيار أو التسمية والتكرار. الملاحظة المقبولة هي استجابة تواصل مفهومة، لا درجة آلية.

### الانتباه المشترك والتقليد واتباع التعليمات البسيطة
يمكن للمرافق استخدام أوامر قصيرة مثل «أشر إلى…» و«أين…؟» و«قل…»، مع متابعة انتباه الطفل وتقليده للاسم.

### اللعب الغني باللغة والتفاعل المستجيب — للمربي/المدرب
التعليمات المدمجة تشجع الانتظار قبل الصوت، والاستجابة للمحاولة، وتوسيع الكلمة وربطها بواقع الطفل.

## القبول التشغيلي

- الصور مرتبطة بالمفردات ويعمل العرض بالعربية أو English أو كليهما.
- لغة النطق مستقلة: عربي أو English أو اللغتان بالتتابع.
- تغيير المستوى يفتح أول تصنيف خاص به.
- اختيار التصنيف ينقل المستخدم إلى شاشة التعلم.
- المراجعة العشوائية تعرض عشر مفردات متنوعة.
- زر التعليمات يقدم مسارًا للمربي/المعلم ومسارًا للطفل الواعي مع جولة داخل التطبيق.
- التحديثات تتحقق تلقائيًا عند الفتح والعودة للتطبيق وتفعّل Service Worker الجديد.

## الحدود

لا تشخيص لتأخر اللغة، ولا تقييم آلي لمخارج الحروف، ولا ادعاء بأن وضع English منهج لغة شامل. الهدف ممارسة المفردات والاستماع والإشارة والتسمية والتكرار بطريقة بسيطة وآمنة.
