# الغولف الصغير
التطبيق السادس في تبويب التسلية؛ هوية `mini-golf` ومسار واحد للفئتين 1–4 و4–8. اثنا عشر مستوى ظاهراً و٣٦ مساراً، مع ست مغامرات مقترحة لكل فئة وثلاثة أجواء. مضرب ومقبض دوار بجانب الكرة باللمس أو الفأرة؛ أزرار ومنزلق ولوحة مفاتيح بديلة. فردي أو شريكان محليان يتبادلان الدور؛ لا مؤقت أو ترتيب أو منافسة إجبارية.

## اللعب
نسحب المقبض حول الكرة لتدوير المضرب بدقة درجة واحدة، ثم نضغط «اضرب الكرة». السحب وحده لا يطلق ضربة؛ إلغاء اللمس يعيد الاتجاه السابق. يمكن أيضاً استخدام الأسهم والمنزلق أو تركيز الملعب والتحريك بأسهم لوحة المفاتيح والضرب بـEnter أو Space. أول مستوى يحتفظ بضربة مساعدة للصغير مع شرح ظاهر. المسار المنقط اختياري ويعرض نتيجة المحاكاة حتى الاستقرار، بما فيه الارتدادات. الكرة السريعة تمر فوق الحفرة ولا تدخلها إلا بسرعة هادئة.

بطاقات العمر تعرض ستة مستويات لكل فئة دون تغيير فئة دخول الطفل أو مسح الجولة. للصغار: البداية، الاتجاه والقوة، الزهور، الألوان، البوابة، الجزيرة؛ للمستكشفين: الحاجز، المنعطفات، الجسر، البوابتان، الارتداد، المتاهة. لكل مستوى ثلاثة مسارات. أزرار «المستوى السابق/التالي» وبطاقات المستويات تستعيد تقدم المستوى المختار؛ بعد إكمال الجولة يظهر الانتقال للمستوى التالي. «الجو السابق/التالي» يغيران الخلفية فقط. إعادة الجولة والتجاوز يحتاجان تأكيداً، والتراجع يعيد الضربة أو الانتقال بعد إعادة الفتح.

## الحفظ والخصوصية
محلي، مستقل لكل هوية وفئة دخول ومستوى وعدد لاعبين. لا تخزين اسم أو PIN، ولا رفع بيانات أو أصوات أو صور. الشريك ضيف رمزي على الجهاز نفسه. تحفظ الأوامر فقط وتشتق المحاكاة الموقع والنتيجة عند الفتح؛ لا ثقة بإحداثيات مخزنة. تحفظ الضربة قبل حركة العرض. عند رفض التخزين يبقى اللعب متاحًا مع تنبيه صريح. حد داخلي 80 ضربة لكل مسار لحماية حجم البيانات؛ يمكن الانتقال أو التراجع دون عقوبة. الجولة الجديدة تستبدل الحالية بعد تأكيد؛ لا أرشيف ولا تراجع عن إعادة الجولة.

## التقنية
ES5 وSVG وFlexbox مع بدائل اللمس القديم، Shared Shell وTouch Guard والهوية ومدير التنزيل. يقتصر السحب على هدف لمس 52×52 فوق المقبض؛ بقية الرسم وحوافه تمرر الصفحة. SVG يتكيف مع المقاسات دون صور كبيرة. نغمات محلية وتعليمات MP3 مسجلة مسبقاً اختيارية؛ لا توليد صوت أو تحميل نموذج على جهاز الطفل. تقليل الحركة يعرض النتيجة فوراً. المحاكاة حتمية ومستقلة عن معدل الإطارات، والتوجيه بالأزرار ولوحة المفاتيح بديل للسحب.

## المدرب والتقدم
زر «المدرب» يشغّل شرح SILMA باليد للمستوى الحالي، ثم محاولة الطفل. العرض يستخدم جولة تدريب منفصلة ويعيد الجولة الأصلية عند الإنهاء. إيقاف مؤقت واستئناف وإعادة سماع وإنهاء متاحة؛ إخفاء الصفحة وتغيير الطفل أو المستوى يلغيان بقية التدريب والصوت. بعد ثلاث ضربات دون اقتراب أو ست دون دخول الحفرة تظهر مساعدة يمكن إيقافها وتعطيلها، مع احترام الكتم. سطر تقدم وتفاصيل محلية تفصل اللعب والتدريب والمحاولة دون اليد؛ العرض الآلي لا يحسب محاولة أو إتقاناً. [تفاصيل السلوك والصوت والقياس](../../../docs/MINI_GOLF_COACH_AR.md).

## Offline والتحديث
عامل مشترك بنطاق التطبيق، تجهيز ذري كامل مع التحقق من البصمات ومدير تحديث المدرسة. تشغيل اللعبة لا يحتاج شبكة بعد التنزيل في متصفح يدعم Service Worker؛ الأجهزة القديمة التي لا تدعمه تحتاج اتصالًا لفتح الصفحة. الحفظ المحلي يعمل مستقلًا. بناء الحزمة: `node tooling/build-golf-offline.cjs` بعد توليد الروابط. لا نحذف بيانات الأطفال عند التحديث.

## التحقق
`node --test apps/1-4/mini-golf/tests/*.test.cjs`؛ اختبارات Chrome في `tests/browser.cjs` و`tests/coach-browser.cjs` و`tests/voice-browser.cjs`، مع Playwright وChrome المثبت. راجع QA_AR.md للنتائج والحدود. يشمل طلب المستخدم التحديث في main؛ حالة live في الكتالوج لا تثبت النشر على الخادم أو تجربة جهاز فعلي.
