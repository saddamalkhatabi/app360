# الغولف الصغير
التطبيق السادس في تبويب التسلية؛ هوية `mini-golf` ومسار واحد للفئتين 1–4 و4–8. أربعة مستويات، ثلاثة مسارات لكل مستوى، وثلاثة أجواء أصلية خفيفة. زر واحد للصغير؛ اتجاه كامل وقوة وحواجز وارتدادات مع التدرج. فردي أو شريكان محليان يتبادلان الدور؛ لا مؤقت أو ترتيب أو منافسة إجبارية.

## اللعب
نوجه الكرة بأزرار أو منزلق، نختار القوة ونضغط زر الضربة. المسار المساعد اختياري ويعرض نتيجة المحاكاة حتى تستقر الكرة، بما في ذلك الارتدادات؛ الكرة السريعة تمر فوق الحفرة ولا تدخلها إلا بسرعة هادئة. نكرر من المكان الجديد، أو نتجاوز المسار بعد تأكيد. بعد دخول الحفرة ننتقل يدويًا، وعند النهاية نبدأ متى أحببنا. السابق والتالي يغيران الجو فقط. إعادة الجولة تحتاج تأكيدًا؛ التراجع يعيد الضربة أو الانتقال، بما فيه تجاوز المسار، ويستمر بعد إعادة الفتح.

## الحفظ والخصوصية
محلي، مستقل لكل هوية وفئة دخول ومستوى وعدد لاعبين. لا تخزين اسم أو PIN، ولا رفع بيانات أو أصوات أو صور. الشريك ضيف رمزي على الجهاز نفسه. تحفظ الأوامر فقط وتشتق المحاكاة الموقع والنتيجة عند الفتح؛ لا ثقة بإحداثيات مخزنة. تحفظ الضربة قبل حركة العرض. عند رفض التخزين يبقى اللعب متاحًا مع تنبيه صريح. حد داخلي 80 ضربة لكل مسار لحماية حجم البيانات؛ يمكن الانتقال أو التراجع دون عقوبة. الجولة الجديدة تستبدل الحالية بعد تأكيد؛ لا أرشيف ولا تراجع عن إعادة الجولة.

## التقنية
ES5 وSVG وFlexbox مع بدائل Android القديم وأهداف لمس 48px، Shared Shell وTouch Guard والهوية ومدير التنزيل. لا مكتبات إضافية ولا استيراد من تطبيق آخر. الخلفيات والأيقونة والغلاف والرسم أصلية لهذا التطبيق؛ SVG يتكيف مع المقاسات دون صور كبيرة. نغمات Web Audio محلية اختيارية مغلقة افتراضيًا؛ لا نطق جديد أو TTS. تقليل الحركة يعرض النتيجة فورًا. خطوة المحاكاة ثابتة، والارتداد والاحتكاك والتقاط الحفرة حتمية ومستقلة عن معدل الإطارات. فتح الخيارات أو إخفاء الصفحة أو تغيير الهوية يلغي الحركة بأمان. Back يغلق الطبقات المؤقتة أولًا.

## Offline والتحديث
عامل مشترك بنطاق التطبيق، تجهيز ذري كامل مع التحقق من البصمات ومدير تحديث المدرسة. تشغيل اللعبة لا يحتاج شبكة بعد التنزيل في متصفح يدعم Service Worker؛ الأجهزة القديمة التي لا تدعمه تحتاج اتصالًا لفتح الصفحة. الحفظ المحلي يعمل مستقلًا. بناء الحزمة: `node tooling/build-golf-offline.cjs` بعد توليد الروابط. لا نحذف بيانات الأطفال عند التحديث.

## التحقق
`node --test apps/1-4/mini-golf/tests/*.test.cjs`؛ فحوص التكامل و183 اختبارًا لتطبيقات التسلية الستة. اختبار Chromium الحقيقي المستقل: `NODE_PATH=<playwright-path> node apps/1-4/mini-golf/tests/browser.cjs`. راجع QA_AR.md للنتائج والحدود. موافقة صدام السابقة تشمل الدمج في main وتأجيل النشر وتجربة الأجهزة لمراجعته؛ حالة live في الكتالوج تعني إدراج التنفيذ في البوابة بعد نشره، ولا تثبت أنه نُشر على الخادم بالفعل.
