## خصوصية هذا التطبيق والحلقة العملية الأساسية
التطبيق الرابع في ترتيب التسلية المعتمد بعد استبعاد الذاكرة. لوحة أصلية من زر يضيء بيتًا، وعجلة تفتح مظلة، ورافعة تحرك مركبة، ومنزلق يغيّر مروحة الهواء. لا كاميرا أو إمالة أو لمس متزامن أو أسئلة منفصلة أو خدمة ذكاء اصطناعي. النقر بديل كامل لأي سحب.

## الشاشات وحالاتها
اللعب مباشرة: مشهد حي وأدوات تحكم كبيرة. المستوى الأول زر واحد مع مرافق؛ الثاني استكشاف بأربع أدوات؛ الثالث مهمات من حالتين؛ الرابع مهمات من ثلاث إلى أربع حالات. 6 مهمات لكل من المستويين الثالث والرابع. الحالات المرئية المطلوبة هي شرط الاكتمال؛ ترتيب البطاقات إرشاد قابل للاستكشاف، وليس اختبار حفظ تسلسل نقرات. تعاون بالتناوب بين شريكين أو فردي. مثال قصير قابل للإيقاف لا يعدّل الحفظ، والتلميح والتراجع متاحان. لا انتقال آلي أو مؤقت. إعدادات قابلة للتمرير وBack يغلقها أولًا.

## نموذج البيانات
schema=1؛ settings: level/players/theme/language/sound/motion/hints؛ selected: المهمة المحفوظة لكل مستوى؛ rounds: جولات بمفتاح المستوى ومعرف المهمة. كل جولة: machine(light,wheel,lever,wind),turn,history(max30). تحقق من القيم والهوية والبنية عند الاسترجاع. الحفظ بعد كل تغيير، وعزل الطفل عن الزائر وفئة الدخول. التراجع يعيد الأداة والدور معًا؛ لا يحتسب الضيف الثاني على حساب آخر. المهمة المحفوظة لا تفقد عند السابق/التالي أو تغيير العالم. لا تخزين PIN أو أسماء جديدة.

## المحتوى الأولي والصوت
3 عوالم SVG أصلية (الحديقة، الميناء، المحطة القمرية)؛ لكل منها بيت أو محطة ومركبة ومظلة ومروحة. 12 مهمة ثنائية اللغة ونتائج مرئية للقيم المختلفة. نغمات Web Audio قصيرة واختيارية ومغلقة افتراضيًا؛ لا نطق جديد أو موسيقى دائمة أو استيراد موارد تطبيق آخر. لا تعديل تسجيلات SILMA أو تشجيع الأسماء.

## التكامل مع التطبيقات السابقة
هوية fun-wonder-machine ومسار واحد للفئتين 1–4 و4–8. دخول الفئة الصغيرة يبدأ المستوى الأول، والكبرى الثالث. Shared Shell وShared Touch Guard والهوية والتنزيل الذري للمنصة. Relative-only، لا تغيير لخدمات الحساب أو الاستضافة. لا نقل تطبيق مستقل إلى Sites ولا تكرار لعبة ذاكرة أو بطاقات مؤجلة.

## Big TAB Android 4.4.2 وOffline
ES5، Flexbox مع -webkit ومواضع بسيطة بدل Grid/clamp. أهداف لمس 48px؛ العجلة والرافعة تعملان بالنقر، والمنزلق له زرا نقصان وزيادة كبديل كامل للسحب. commit واحد عند انتهاء تغيير range كي لا يتبدل دور الشريك أثناء السحب. لا منع تمرير الصفحة أو نسخة موازية من Touch Guard. غياب Web Audio لا يمنع اللعب؛ غياب Service Worker يعني الاتصال مطلوب ولا ادعاء Offline له. لا فقد للحفظ عند تغيير الاتجاه أو التحديث.

## Definition of Done
فحص أهداف الحالة النهائية لا عدد النقرات، واستعادة كل مهمة، والتراجع والشراكة والقيم الفاسدة، وعزل الهوية ورفض التخزين، وإلغاء العرض عند الخروج أو الخلفية أو التحكم، وتقليل الحركة والصوت غير المتاح. فحص بصمات الحزم والسجلات الإلزامية والروابط والعقود وعدم تراجع التطبيقات الثلاثة السابقة. اختبار الأجهزة والمتصفح الفعلي مؤجل إلى صدام بإذنه الصريح قبل بدء هذا التطبيق؛ لا ادعاء إجراء اختبار طفل أو Big TAB أو لقطات واجهة فعلية.
