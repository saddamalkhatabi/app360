# سباق السيارات الصغيرة
التطبيق السابع في تبويب التسلية، هوية `little-car-race` ومسار واحد للفئتين 1–4 و4–8. أربعة مستويات × ثلاثة مضامير، وثلاثة أجواء أصلية وثلاث سيارات. يبدأ الصغير بزر واحد. ثم يختار المسار ويجمع رايات اختيارية، مع مخاريط وممرات مفتوحة في المستويات التالية. السيارة تتبع انحناء الطريق تلقائيًا؛ ليست تدريب قيادة واقعية.

## الحلقة
انطلق، بدّل المسار بأزرار اليسار/الوسط/اليمين، توقف أو أكمل إلى خط النهاية. توقف مساعد قبل المخروط دون اصطدام أو خسارة أو إعادة إجبارية. عندما يفتح الطريق نضغط انطلق مجددًا. ثلاث سرعات اختيارية؛ المستوى الأول يثبت الأبطأ. لكل لاعب ثلاثة مضامير؛ الشريكان محليان ويتبادلان بعد المضمار، دون ترتيب أو مقارنة. لا مؤقت تنافسي ولا إعلانات أو شبكة مطلوبة للحلقة الأساسية.

«ارجع قليلًا» يعيد نحو ثانية ونصف من الخطوات ويلغي الرايات اللاحقة، أو يعيد آخر انتقال. يمكن تجاوز مضمار أو إعادة الجولة بتأكيد؛ إعادة الجولة تستبدل الحالية ولا يمكن التراجع عنها. تغيير الجو أو السيارة أو اللغة لا يمحو التقدم. لكل مستوى وعدد لاعبين جولة مستقلة.

## الحالة والخصوصية
حفظ محلي معزول حسب الهوية وفئة الدخول، دون أسماء أو PIN أو رفع بيانات. الشريك ضيف رمزي على الجهاز نفسه. نحفظ الأوامر المضغوطة فقط؛ يعاد اشتقاق تقدم السيارة والرايات والتوقفات من الأوامر، ولا تثق الاستعادة بنتائج أو إحداثيات مزورة. حفظ كل نصف ثانية أثناء القيادة، وفور الراية والتوقف والنهاية وتغيير المسار والإغلاق أو الخيارات أو تبديل الهوية. قد تضيع آخر نصف ثانية عند إنهاء المتصفح فجأة دون أحداث إغلاق. الفتح دائمًا متوقف؛ لا حركة تلقائية. رفض التخزين لا يمنع اللعب ويظهر تنبيهًا صريحًا.

## المحاكاة والرسم
خطوة ثابتة 100ms؛ لا تعويض للزمن أثناء الإخفاء أو العودة. مخاريط ثابتة، ومسافة توقف مشتقة لتبقى الرسوم منفصلة في العرض المتحرك والخريطة الكاملة. كل ممر له طريق صالح، وكل الرايات قابلة للوصول. خط الإرشاد اختياري ولا يقود السيارة بدل الطفل. الحركة المرئية منفصلة عن الخطوة المنطقية؛ عند تقليل الحركة يعرض المضمار كاملًا مع تقدم السيارة عليه بدل تمرير الخلفية. SVG أصلي وخفيف وES5 وFlexbox، بلا مكتبة تشغيل أو استيراد من تطبيق آخر.

نغمات Web Audio محلية قصيرة عند الانطلاق والراية والنهاية، اختيارية ومغلقة افتراضيًا؛ لا TTS جديد أو تسجيلات كبيرة. يتم تحميل هوية المدرسة ومشغل التشجيع المشترك وعناصر التنقل وTouch Guard من المنصة. Back يغلق الخيارات والتأكيد أولًا، وEscape يوقف القيادة كذلك. لا تحكم بالإمالة أو سحب أو أحداث لمس مخصصة.

## Offline والتحقق
عامل مشترك بنطاق مستقل؛ تنزيل ذري والتحقق من البصمات ومدير تحديث المدرسة. الأجهزة التي لا تدعم Service Worker تحتاج اتصالًا لفتح الصفحة؛ الحفظ المحلي مستقل. بناء الحزمة: `node tooling/build-race-offline.cjs` بعد توليد الروابط. لا تمسح بيانات الطفل عند التحديث.

اختبارات: `node --test apps/1-4/little-car-race/tests/*.test.cjs`. اختبار Chrome الفعلي يستخدم Playwright وAcorn من مسار QA معزول: `NODE_PATH=<qa-modules> APP360_TEST_CHROMIUM=<chrome-path> node apps/1-4/little-car-race/tests/browser.cjs`. القيادة في اختبارات المقاسات تستخدم ساعة متصفح مضبوطة؛ اختبار Offline يستخدم الوقت الحقيقي. راجع QA_AR.md للنتائج والحدود. الدمج في main مأذون؛ تحديث الخادم وتجربة الطفل والتاب القديم مؤجلة لصدام. live في الكتالوج يدرج التطبيق في البوابة عند نشرها، ولا يثبت نشره على الخادم.
