# X وO · ساحة الأصدقاء

التطبيق الثاني في تطبيقات التسلية. المصدر الوحيد apps/1-4/tic-tac-toe، للفئتين 1–4 و4–8.

- تعاون مستقل لإكمال خط مضاء مع المرافق، لاعبان محليان بالتناوب، أو خصم محلي بثلاث درجات. أوضاع اللعب ودرجات الجهاز ظاهرة مباشرة في الشاشة الرئيسية.
- المستوى الحالي واضح، والسابق والتالي أسفل اللوحة؛ في التعاون أو مع الصديق يظهر «ابدأ المستوى 1» للانتقال إلى اللعب مع الجهاز.
- تُحفظ جولة مستقلة لكل درجة وللتعاون وللصديق، وتُستعاد عند التنقل وإعادة التحميل. تغيير المظهر أو اللغة أو الرموز لا يبدأ جولة جديدة.
- رموز X/O أو القط والأرنب، ثلاثة عوالم أصلية SVG، تلميح وتراجع وجولة جديدة.
- حفظ فوري ضمن هوية الطفل وفئة الدخول، دون حساب إلزامي. إعادة فتح دور الجهاز تستكمل حركته.
- Web Audio اختياري بنغمات أصلية، بلا كلام أو موسيقى مستمرة. لا أصول أو خطوط خارجية.
- ES5 وخانات لمس كبيرة وShared Touch Guard. لا لمس متزامن مطلوب.
- تنزيل عبر مدير المنصة؛ المتصفح غير الداعم للعامل يحتاج اتصالًا. لا تعديل لخدمات الهوية.

اختبار: node --test apps/1-4/tic-tac-toe/tests/*.test.cjs

نقطة الدخول للفئة الأكبر: index.html?launch_age=4-8&launch_level=2
الـ launch_age يحدد الإعداد الافتراضي فقط؛ اختيار الطفل المحفوظ له الأولوية.
