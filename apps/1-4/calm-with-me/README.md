# مشاعري معك: أحتاج مساعدة

تطبيق محلي للفئة `1-4` بهوية ثابتة `a1-calm` ومسار وحيد `apps/1-4/calm-with-me/`.

النسخة الحالية **Build v3 / package 0.3.0**. بُنيت ممارسة التنظيم المشترك والانتقال المصور والتنفيذ الفعلي لخدمات التطبيقات المرتبطة، لكن **الحالة تبقى `planned` ولا يُعلن التطبيق live** قبل اختبار الأجهزة واللمس والانقطاع والتحديث وتجربة ملاءمة موثقة.

## رابط الاختبار

`https://raw.githack.com/saddamalkhatabi/app360/main/apps/1-4/calm-with-me/index.html?v=3`

يجب أن يظهر في رأس التطبيق النص **نسخة الاختبار v3** للتأكد من عدم عرض Cache قديم.

## ما بُني في التطبيق الأساسي

- وضع طفل ببطاقات كبيرة للإشارة أو الحاجة، مع إمكانية تجاوز تسمية الشعور تمامًا.
- كلمات مشاعر اختيارية ومحايدة لا يستخدمها التطبيق لاستنتاج حالة داخلية.
- مكتبة مساعدات تظهر كخيارات قابلة للرفض، ويمكن للمرافق تفعيلها وتعطيلها وإعادة ترتيبها بالأسهم.
- إضافة مساعدات أسرية خاصة بنص وصورة محلية وصوت محلي اختياري، دون رفع الملفات إلى خادم.
- منشئ بصري `الآن ← بعد ذلك` باستخدام مورد الصور المشترك أو صورة من الجهاز.
- حفظ عدة خطط محليًا وإعادة فتحها وتعديلها وحذفها.
- طباعة بطاقة الانتقال أو خطة المساعدة.
- مراجعة وصفية للمرافق: ما عُرض، ما قُبل، ما ساعد، ما لم يساعد، وما الذي سيتغير في المرة القادمة.
- TTS اختياري وصوت مسجل محلي اختياري؛ لا تتوقف الممارسة إذا تعذر الصوت.
- استمرار الممارسة في الذاكرة إذا تعذر `localStorage` مع تنبيه صريح بأن البيانات لم تُحفظ وخيار التصدير.

## التنفيذ بين تطبيقات مختبر 360 — Build v3

يقرأ التطبيق `data/app-links-registry.json` وأرشيف `links.json` لكل تطبيق مرتبط، ولا يخزن Domain ثابتًا داخل الخطة.

التطبيقات المرتبطة حاليًا:

- `a1-first-words` — كلماتي مع أشيائي.
- `a1-imitate` — دوري ودورك.
- `a1-screen-move` — ألعاب إبداعية عبر الشاشة أو بدونها.
- `a1-drawing-writing` — لوحة الطفل للرسم والكتابة المبكرة.

يمكن للمرافق اختيار التطبيق ثم الخدمة ثم البطاقة/اللعبة/التجربة ووضعها في `الآن` أو `بعد ذلك`. عند التنفيذ يُولد `launch_id`، ويُفتح التطبيق الأصلي عبر رابط نسبي، وتُسجل أحداث `opened / ready / completed / returned` في `app360:interop:v1:events`.

بعد الإكمال يظهر **العودة للخطة**. ومنذ Build v3 يوجد أيضًا **العودة دون إكمال**؛ هذا المسار يعيد المستخدم إلى الخطة دون تحويل النشاط إلى مكتمل.

لا تُفتح خطوة `بعد ذلك` للتنفيذ قبل إكمال `الآن` أو تجاوزه صراحة.

## دورات التنفيذ والسجل

الخطة المحفوظة قابلة للاستخدام مرات متعددة. زر **بدء دورة تنفيذ جديدة** يؤرشف الدورة السابقة بدل الكتابة فوقها، لذلك يمكن مراجعة تاريخ استخدام الخطة عبر الزمن دون تحويل ذلك إلى نقاط أو تقييم للطفل.

Build v3 يوسع النسخة الاحتياطية لتشمل:

- `plans`
- `reviews`
- `library`
- `custom_transitions`
- `execution_runs`
- `execution_history`
- `interop_events`

كما يستعيد الاستيراد هذه البيانات مع الدمج دون حذف الخطط الحالية.

## التوافق القديم

المسار الأساسي مكتوب بـES5 ويستخدم `Touch Events + click` مع منع اللمسة المكررة، وFlexbox بدل CSS Grid. لا يحتاج Pointer Events ولا السحب لإكمال أي مهمة؛ ترتيب المساعدات يتم بأزرار أعلى/أسفل.

بوابة الربط المشتركة `assets/js/app-link-host.js` تستخدم في Build v3 مواضع `top/right/bottom/left` بدل الاعتماد على CSS `inset`، ولها fallback للـ`origin` وزر عودة واضح قبل الإكمال. لا يُعد Android 4.4 معتمدًا نهائيًا قبل الاختبار على الجهاز الحقيقي.

## PWA وOffline

Service Worker الحالي هو `app360-app-calm-with-me-v3`. يخزن Shell التطبيق وملفات التكامل وسجل الروابط ومصادر الكلمات والتجارب والألعاب المطلوبة. كما يحاول مطابقة المورد المخزن بدون Query String عند اختلاف أرقام النسخ، لتقليل مشاكل الانتقال بين الإصدارات.

لا يزال اختبار Offline والتحديث وعدم فقد البيانات على أجهزة حقيقية بوابة قبول إلزامية قبل `live`.

## التخزين والخصوصية

مفتاح التخزين الأساسي:

`app360:a1-calm:schema-1.0:state`

سجل الربط المشترك:

`app360:interop:v1:events`

البيانات المحلية تشمل الخطط والمراجعات ومكتبة المساعدات المخصصة ودورات التنفيذ. صور وصوت الأسرة يقرآن كبيانات محلية فقط ولا توجد خدمة رفع أو حساب أو API key.

## المورد المرئي المشترك

يستخدم التطبيق `resources/early-child-visuals/` الذي رُقّي من مجموعة صغيرة أصلية كانت داخل `say-and-name` بعد ظهور مستهلك ثانٍ فعلي. لم يُنشأ اعتماد مباشر من تطبيق إلى تطبيق؛ الربط يتم عبر عقد الروابط النسبي.

## التحقق

Build v3 البرمجي اجتاز `Validate App 360 Lab` في GitHub Actions Run `460`، ويشمل التحقق من المنصة، Blueprints، روابط التطبيقات، التوافق القديم لبوابة الربط، محتوى `calm-with-me`، عقد interop، واختبار مكتبة 200 تجربة.

داخل مجلد التطبيق:

`node tooling/validate-content.js`

`node tooling/validate-interop.js`

وعلى مستوى المستودع:

`pnpm validate`

`pnpm test`

راجع `QA_ACCEPTANCE_AR.md` قبل تغيير الحالة إلى `live`.

## الحدود

التطبيق لا يشخص الانفعال أو الحالة النفسية، ولا يستنتجها من البطاقة أو اللمس، ولا يجبر الطفل على التنفس أو السكون أو إكمال تسلسل، ولا يستخدم مؤقتات أو نقاطًا أو مكافآت للضغط على الطفل. هو أداة مساعدة للتنظيم المشترك والانتقالات، وليس علاجًا أو بديلًا عن مختص عند الحاجة.
