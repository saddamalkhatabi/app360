# بوابة قبول — مشاعري معك: أحتاج مساعدة

تاريخ بناء النسخة: 2026-09-22

الحالة الحالية: **التنفيذ موجود، لكن الاعتماد النهائي و`live` ممنوعان حتى إكمال الاختبارات الفعلية أدناه.**

## مراجعة ملاءمة ثابتة — من التنفيذ

- [x] يوجد زر صريح لتجاوز تسمية الشعور.
- [x] يوجد مسار صريح لرفض المساعدة والاستمرار.
- [x] لا توجد درجة للهدوء أو السلوك.
- [x] لا توجد مؤقتات أو نقاط أو مكافآت تضغط على الطفل.
- [x] لا توجد تمارين تنفس مفروضة.
- [x] المساعدات تظهر بصيغة خيارات قابلة للتخصيص والرفض.
- [x] كلمات الشعور اختيارية ولا تُستخدم لاستنتاج الحالة النفسية.
- [x] المراجعة بعد الموقف وصفية وموجهة للمرافق.
- [x] الصور والصوت الأسريان يقرآن محليًا ولا توجد عملية رفع إلى خادم.
- [x] يوجد بديل نصي/بصري عند تعذر الصوت.
- [x] يوجد تنبيه صريح عند تعذر التخزين، ويستمر النشاط مع إمكانية التصدير.
- [x] ترتيب المساعدات لا يشترط السحب؛ توجد أزرار أعلى/أسفل.
- [x] المسار الأساسي ES5 + Touch Events/click bridge + Flexbox.

## اختبار ممارسة كامل

- [ ] اختيار إشارة ثم اختيار مساعدة ثم بناء `الآن/بعد ذلك` وحفظ الخطة.
- [ ] تجاوز تسمية الشعور ثم إكمال الانتقال بلا عقوبة.
- [ ] رفض المساعدة ثم إكمال الانتقال بلا عقوبة.
- [ ] فتح خطة محفوظة وتعديلها وحفظ نسخة جديدة.
- [ ] طباعة بطاقة الانتقال والتأكد من وضوحها على A4.
- [ ] تصدير خطة واحدة وتصدير الكل ثم إعادة الاستيراد.
- [ ] حذف خطة واحدة دون حذف بقية الخطط.
- [ ] إضافة مساعدة أسرية بصورة محلية وصوت محلي ثم إعادة فتح الصفحة والتأكد من بقائها عند توفر التخزين.
- [ ] إضافة خطوة انتقال بصورة محلية واستخدامها في خطة.
- [ ] تسجيل مراجعة للمرافق ثم تصدير البيانات والتأكد من وجودها.

## التخزين والفشل الآمن

- [ ] اختبار `localStorage` طبيعي: حفظ ← إغلاق ← إعادة فتح ← استرجاع.
- [ ] حظر/تعطيل التخزين: تستمر الممارسة ويظهر تنبيه بأن الحفظ غير حاصل.
- [ ] ملء التخزين أو محاكاة Quota failure: لا تنهار الواجهة ويظل التصدير متاحًا.
- [ ] ملف صورة أكبر من الحد: يرفض بلطف ويبقى البديل النصي/الرمزي صالحًا.
- [ ] ملف صوت أكبر من الحد: يرفض بلطف ويعمل النص/TTS أو الواجهة البصرية.

## الصوت

- [ ] جهاز حديث بصوت عربي: TTS يعمل عند تفعيله.
- [ ] جهاز بلا صوت عربي: تظهر رسالة واضحة وتستمر الواجهة بصريًا.
- [ ] تعطيل الصوت من وضع المرافق: لا يمنع أي نشاط.
- [ ] صوت محلي مخصص: يعمل عند دعم الجهاز، ولا يكون شرطًا لإكمال الخطة.

## قبل `live`

لا تغير `status` إلى `live` ولا تضف `href` إلى الكتالوج قبل اكتمال البنود الحرجة أعلاه، وبالأخص اختبار Big TAB HD واللمس الفعلي وOffline والتحديث وعدم فقد البيانات. بعد ذلك حدّث الكتالوج والعقد، شغّل أدوات البناء والتحقق، ووثّق نتيجة تجربة مستخدم مناسبة دون الادعاء بأثر تربوي لم يُقَس.
