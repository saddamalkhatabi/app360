# تحقق رافعة مدينة الألعاب — 30 أكتوبر 2026

الإصدار 2: سحب يدوي للرافعة، تحكم مثبت عليها، مؤشر توازن، إسقاط صريح وإرجاع القطعة عند اختلاف الشكل أو الاتجاه أو الترتيب أو التوازن، وأربعة مستويات ظاهرة بستة تحديات لكل مستوى.

## نتائج محلية

اجتازت ٣٣ حالة اختبار للمنطق والتشغيل والتكامل: إكمال التحديات الأربعة والعشرين، و١٢ دورًا لشريكين في كل مستوى، ١٠٠ جلسة أوامر مختلطة دون فقد أو ازدواج قطع، حدود السجل وفساد الحفظ واستيراد v1، الأوزان والتأرجح والاستقرار، رفض إسقاط غير متزن أو خارج المحاذاة، الترتيب والتدوير، إرجاع القطعة والتراجع عنه، تقدم مستقل للتحديات، عزل الهوية والفئة والمستوى واللاعبين، رفض التخزين وتقليل الحركة وBack وEscape وإلغاء callbacks القديمة.

اختبار Chrome فعلي بمحرك المتصفح، مع شاشة لمس محاكاة عبر CDP وفأرة، على: 320×740 و390×844 و844×390 و768×1024 و1024×768 و1440×1000. تحققت أزرار 48px وبقاؤها داخل المشهد، وعدم التمدد الأفقي، العربية والإنجليزية، حفظ القطعة وإعادة الفتح، تغيير المستويات والتحديات، عدم الإسقاط بمجرد السحب أو نقر قالب، وإرجاع القطعة ثم إعادة المحاولة والتدوير.

اختُبر كذلك Touch fallback مع تعطيل PointerEvent ومحاكاة وكيل Android 4.4 وتشغيل Shared Touch Guard؛ يكتمل السحب قبل حجب النقرة الصناعية. هذا فحص محاكاة ولا يثبت توافق جهاز مادي.

اختُبر التأرجح بزمن إطارات حقيقي وانتظار استقراره قبل الإسقاط، وأُكمل مشروع مرقم. اكتملت كل التحديات الـ٢٤ من الواجهة عبر المساعدة خطوة بخطوة. نُزلت الحزمة ببصماتها، ثم فُصلت الشبكة وأعيد فتح الصفحة وسُحبت قطعة وأُسقطت وحُفظت واستعيدت بعد إعادة الفتح. محاكاة Worker إضافية من الجذر ومن /school/ تتحقق من تجاوز طلبات الهوية للكاش.

فُحصت جميع ملفات runtime باستخدام Acorn بوضع ES5. أجري فحص بصري للقطات الهاتف والكمبيوتر والمستوى المتقدم والمشروع المكتمل. اجتاز فحص حداثة المواصفات المشتقة. الحزمة الذرية ٩٥ ملفًا وأقل من ٧٠٠ ألف بايت، مع تطابق كل بصمة وحجم. بصمات الكتالوج المشتركة تحدث في الحزم المستهلكة. أُدمج تحديث الغولف المنشور أثناء العمل، وتحقق تطابق ٢٣ حزمة أخرى مع main بعد استثناء بصمة الكتالوج المشترك التي تتغير مع هذا الإصدار.

## إعادة الاختبار

```text
node --test apps/1-4/toy-city-crane/tests/*.test.cjs
node apps/1-4/toy-city-crane/tests/browser.cjs
node tooling/build-blueprints-active.js --check
node tooling/build-crane-offline.cjs
```

Playwright وAcorn أدوات اختبار فقط، ولا اعتماد تشغيل جديد. يمكن تعيين APP360_TEST_CHROMIUM وAPP360_CRANE_SCREENSHOTS. يستمر Workflow التسلية الموجود في تشغيل هذه الاختبارات عند push إلى main.

## حدود التحقق

لم تُجر تجربة مع طفل أو جهاز لمس مادي أو Big TAB Android 4.4.2. دعم المتصفح القديم مبني على ES5 وSVG وبدائل Touch/Mouse والأسهم؛ لا يعد ذلك توثيقًا لجهاز لم يختبر. التقدم محلي، ولا ادعاء مزامنة حساب أو نشر حي تم التحقق منه. طلب المستخدم يجيز رفع التعديلات إلى main.
