# رافعة مدينة الألعاب · Toy City Crane

التطبيق الثامن في دفعة التسلية للفئتين 1–4 و4–8، بمسار وحيد `apps/1-4/toy-city-crane/`. افتح index.html عبر خادم المدرسة. دخول 1–4 يبدأ بالمستوى 1، و4–8 بالمستوى 3؛ الجاهزية تحدد المستوى المناسب. ثلاثة مشاريع لكل لاعب، فردي أو تناوب ضيف محلي. أربعة مستويات، ثلاثة أجواء أصلية، مطابقة شكل ثم اتجاه، مساعدة خطوة وتراجع وحفظ فوري.

المستوى 1: انقر قطعة ثم قالبها؛ زر الالتقاط/الوضع بديل مساعد. المستويات 2–4: النقر على الخانة يحرك الرافعة، ثم زر الالتقاط/الوضع ينفذ؛ الأسهم بديل واضح، والتدوير في المستوى 4. الخطأ يبقي القطعة معلقة. النص للمرافق؛ الأشكال والأزرار والإشارة تكفي للممارسة الأساسية. لا نطق جديد أو صوت مفروض.

المنطق في core.js حتمي ES5، والرسم الأصلي في art.js وassets؛ الحركة تجميلية فقط، والحفظ قبلها. لا اعتماد تشغيل جديد أو تحميل وسائط كبيرة. النغمات محلية اختيارية. العزل المحلي حسب هوية الجلسة وفئة الدخول والمستوى وعدد اللاعبين؛ لا مزامنة تقدم معلنة. تجاهل سجل غير قانوني يعيد الجولة فقط. التراجع يعيد آخر أمر حقيقي (التحريك والالتقاط أمران في النقر المساعد)، ويستطيع إعادة آخر انتقال مشروع/دور. تجاوز/إعادة الجولة بتأكيد. جولة مكتملة تبقى حتى يبدأ المستخدم غيرها. لا جمع أسماء أو تقييم قدرات.
