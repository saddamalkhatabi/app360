# سلة الاكتشاف: فرز ولمس ونقل

تطبيق عملي للفئة 1–4 يحوّل الشاشة إلى مُعِدّ قصير لمهمة واقعية باليد والجسم، لا إلى لعبة شاشة حسية.

## الحلقة
مواد ومكان → فحص سلامة → بناء مهمة → تنفيذ خارج الشاشة → أبسط/تحدٍ إضافي → نتيجة وصفية → حفظ/طباعة.

## الخصائص
- مواد ومكان ونوع حركة وخاصية واحدة.
- بوابة سلامة إلزامية قبل توليد المهمة.
- نقل، فرز، مطابقة، تكديس، لمس، ومسار حركي.
- مصمم مرافق لتعديل التعليمة والبدائل والسلامة.
- حفظ محلي، استرجاع، حذف، تصدير JSON، وطباعة من نفس نموذج المهمة.
- TTS اختياري مع بقاء النص كاملًا.
- Offline-first عبر Service Worker مستقل.
- ES5 + Flexbox ومسار Legacy؛ اعتماد Big TAB النهائي ينتظر التجربة الفعلية على الجهاز.

لا يقدم التطبيق تشخيصًا أو درجة حسية/حركية ولا يقارن الأطفال.
