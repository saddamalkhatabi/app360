# بولينغ المرح · Playful Bowling

التطبيق الخامس في تبويب التسلية. مصدر واحد للفئتين 1–4 و4–8؛ يبدأ الصغير بزر واحد، وتبدأ الفئة الأكبر بست قوارير واتجاه وقوة.

- أربعة مستويات: قارورة كبيرة، ثلاث قوارير، ست، ثم عشر. ثلاثة ملاعب SVG أصلية وثلاث كرات برسومات ثعلب وقطة وصاروخ.
- ثلاث مجموعات قوارير لكل لاعب، ولكل مجموعة رميتان كحد أقصى؛ إسقاط الجميع ينهي المجموعة مبكرًا. الانتقال بزر واضح. فردي أو لاعبان يتناوبان محليًا، والثاني ضيف. لا حساب بطولة أو مكافآت متسلسلة أو مقارنة أطفال.
- اتجاه مادي ثابت لليمين واليسار في اللغتين، ومنزلق مع أزرار بديلة. القوة تغير مدى الكرة وانتقال الاصطدام. المسار المساعد اختياري. النتيجة حتمية ولا تتغير بسرعة الجهاز.
- الرمية تحفظ قبل بدء الحركة. إعادة الفتح أثناء الحركة تعرض نتيجتها دون تكرارها. فتح الخيارات أو إخفاء الصفحة يلغي المواعيد المتأخرة بأمان. تقليل الحركة يعرض النتيجة مباشرة.
- التراجع يعيد الرمية أو انتقال الدور أو بدء الجولة الجديدة. لكل مستوى وعدد لاعبين جولة مستقلة؛ تغيير العالم أو الكرة أو اللغة يحافظ عليها. تأكيد قبل استبدال الجولة؛ تاريخ التراجع محدود بـ20 لقطة.
- عزل حساب الطفل عن الضيف وعن الأطفال الآخرين، مع تنبيه عند تعذر الحفظ واستمرار اللعب. لا تجمع اللعبة أسماء أو تسجيلات أو بيانات إضافية.
- مؤثرات Web Audio اختيارية مغلقة افتراضيًا؛ لا TTS أو تغيير تسجيلات SILMA. غياب Web Audio لا يمنع اللعب.
- ES5 وFlexbox وShared Shell وTouch Guard وحزمة تنزيل ذرية. لا تعتمد على ملفات تطبيق آخر. لا Service Worker على Android 4.4؛ اللعب فيه يحتاج اتصالًا. لا ندعي اختبار Big TAB فعليًا.

الاختبارات: `node --test apps/1-4/fun-bowling/tests/*.test.cjs`.

تحديث الكتالوج: `node tooling/build-blueprints-active.js` ثم `node tooling/build-public-links.js` ثم `node tooling/build-bowling-offline.cjs`. بيانات البناء مصدرها `data/catalog.json`.

دخول الفئة الأكبر: `index.html?launch_age=4-8`. إعداداتها المحفوظة تتقدم على المستوى الافتراضي. تجربة المتصفح والأجهزة والطفل والنشر مؤجلة لمراجعة صدام وفق إذنه؛ راجع QA_AR.md.
