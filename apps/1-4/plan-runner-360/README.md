# مخطط جلسات 1–4

أداة للمدرب لبناء وتشغيل جلسة الفئة 1–4، مع أنشطة الطفل ولعب واقعي وجلسة مستجيبة ومراجعة قصيرة. تظل الهوية `a1-plan-runner` والمسار `apps/1-4/plan-runner-360/` ومفاتيح البيانات كما هي، لحفظ خطط المستخدمين الحالية.

## الاستخدام

المدرب يختار الأنشطة ويرتبها ويحدد المدة وطريقة الانتقال. الطفل يشارك في الأنشطة التي يفتحها المدرب، ويظل الانقطاع والمساعدة والتقصير جزءًا طبيعيًا من الجلسة. تسمية التطبيق تحدد نطاقه؛ مخطط 4–8 مقترح مستقل سيستفيد لاحقًا من محرك مشترك دون نسخ بيانات الفئة السابقة.

## البنية الفعلية

- سجل `data/app-links-registry.json` وملفات `links.json` هما مصدر اختيار التطبيقات والخدمات والعناصر.
- تشمل الأنشطة التسعة الكلمات والتقليد وألعاب الشاشة والرسم والمشاعر والسلة والروتين وتركيب الأشكال وتركيب الصور.
- `data/presets.json` المصدر الوحيد للنماذج الأربع والعشرين: ثمانية لكل مستوى 1–2 و2–3 و3–4. تضم أمثلة لتركيب الصور والأشكال بوصفها خطوات عادية.
- لا تُحقن أمثلة عبر تغليف XMLHttpRequest. `presets-merge-v3.js` يحتفظ فقط بتحميل تكامل الأسرة للتوافق مع صفحة التشغيل الحالية.
- كل خطوة تحفظ app_id وroute_id والرابط والمدة وطريقة الانتقال؛ المخطط لا ينسخ محتوى التطبيق الهدف.
- iframe للتشغيل، مع خيار تبويب للرابط الخارجي، وسجل مستقل لكل run_id، وحفظ وتصدير واستيراد محلي.

## جلسة مستجيبة

اهتمام الطفل ومكان اللعب والمواد والطاقة والتركيز الواحد → بداية من مبادرة الطفل → استجابة المرافق → نشاط مساند اختياري → نهاية متوقعة → ملاحظة ما ساعد والتعديل المقبل. زر إخفاء الشاشة يدعم الاستمرار في الواقع. المراجعة تخص الجلسة واختيارات المرافق ولا تنتج تشخيصًا أو درجة للطفل.

## قبول التحديث

اختبر اختيار كلا نوعي الألغاز، إضافة خطوة بالمدة والانتقال، نسخ نموذج وتعديله، تشغيله والعودة أو الانتقال، واستعادة الخطط السابقة تحت نفس مفتاح التخزين. لا تظهر لافتات إصدار أو إعلان تخص نشاطًا بعينه في واجهة المخطط.

كل تطبيق لاحق يعلن عقد روابط نسبيًا وهوية عمرية ونوع الاستخدام. لا يعلن Offline إلا بعد اختبار الكاش والأصول الفعلية، ولا يدرج تطبيق planned بوصفه تطبيقًا صالحًا للتشغيل.
