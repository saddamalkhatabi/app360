# الحزم المشتركة — packages/

هذا المجلد للمكونات **القابلة لإعادة الاستخدام فعليًا** بين أكثر من تطبيق أو خدمة.

## قاعدة منع الهدر ومنع التجريد المبكر

لا ننقل أي كود من تطبيق إلى `packages/` لمجرد أنه قد يكون مفيدًا يومًا ما. ينتقل عندما يتحقق واحد من الآتي:

1. يوجد مستهلكان حقيقيان أو أكثر للكود نفسه.
2. هو عقد منصة ثابت يجب أن يكون موحدًا مثل `@app360/contracts`.
3. هو Runtime/SDK يحتاج توافقًا واختبارات مستقلة ويستفيد منه أكثر من منتج.

بهذه القاعدة نتجنب خطأين معًا: **تكرار المكتبات** و**بناء مكتبات عامة ضخمة قبل الحاجة**.

## الحزم المتوقع استخراجها عندما يظهر المستهلك الثاني

- `@app360/ui-kit` — مكونات RTL وإتاحة وأحجام لمس.
- `@app360/practice-core` — حلقات الممارسة والتدرج والتقدم.
- `@app360/audio-runtime` — TTS + recorded audio + legacy fallback.
- `@app360/storage` — Local-first storage + migrations.
- `@app360/pwa` — Service worker/update helpers.
- `@app360/sync` — مزامنة/جلسات جماعية عندما تحتاجها تطبيقات متعددة.
- `@app360/ai-client` — عميل موحد لخدمات AI عند إنشاء بوابة خلفية رسمية.

لا تنشئ هذه الحزم كنسخ فارغة؛ استخرجها من كود عامل عند الحاجة الثانية، ثم ثبت API صغيرًا وواضحًا.
