# @app360/contracts

حزمة صغيرة بلا Dependencies تمثل **العقود الثابتة** التي تتشاركها تطبيقات وخدمات مختبر التطبيق 360: الفئات العمرية، حالات التطبيقات، أنواعها، مستويات العمق، وأنماط التشغيل.

هذه الحزمة هي مثال على قاعدة مهمة في الـmonorepo: ما هو ثابت ومشترك يخرج إلى `packages/`، أما منطق تطبيق واحد فيبقى داخل التطبيق حتى يظهر مستهلك ثانٍ حقيقي له.

الاستخدام في Node:

```js
const { AGE_GROUPS, APP_STATUSES } = require('@app360/contracts');
```

لا تضف هنا كود واجهة أو كود خاص بعمر واحد.
