# Pencil core v1

ES5 canvas primitives shared by drawing-writing-foundations and draw-write-studio. `segment` and `quadratic` preserve the original foundations stroke commands. `line` accepts normalized or pixel points; `artwork` renders normalized stroke/stamp commands, including ordered eraser strokes, for screen, thumbnails, export and print. No app imports or storage. Tested with command-level parity and both browser consumers.
