# مختبر التطبيق 360 — App 360 Lab

مكتبة التطبيقات العملية لمنظومة **الريلز الآمن 360**، منظمة حسب الفئات العمرية ومصممة للانتقال من المشاهدة إلى **الممارسة ثم الإتقان**.

## الدخول

- الواجهة الرئيسية: `index.html`
- الفئات: `ages/<age-group>/index.html`
- التطبيق العامل للرسم والكتابة للفئة 1–4: `apps/1-4/drawing-writing-foundations/index.html`

الفئات المعتمدة:

`1-4` · `4-8` · `8-12` · `12-16` · `16-24` · `24-45` · `45-60` · `60-80`

## مصادر الحقيقة

- `data/catalog.json` — كل التطبيقات والأفكار، حالتها، أولويتها، حلقة الممارسة، والـgoal keys المرتبطة.
- `data/goals.json` — أهداف Safe Reels 360 المرجعية حسب العمر ودور المتعلم/المدرب.
- `docs/FRAMEWORK_AR.md` — عقد البنية والتطوير المستمر.
- `docs/APP_SPEC_TEMPLATE_AR.md` — قالب إلزامي لبدء تطبيق فردي في محادثة مستقلة.
- `docs/ROADMAP_AR.md` — منطق الأولوية وخارطة البناء.

## بناء تطبيق جديد

المسار القياسي الجديد:

```text
apps/<age-group>/<app-slug>/
```

ابدأ من `apps/_template/`، واجعل التطبيق مستقلًا عن بقية التطبيقات. بعد اكتماله حدّث سجله في `data/catalog.json` فقط؛ واجهة الفئة والبحث ستلتقطه تلقائيًا.

> ملاحظة: `/1-4/` أصبح مسار توافق يعيد التوجيه فقط. المصدر الرسمي هو `apps/1-4/drawing-writing-foundations/`.

## التحقق

```bash
node .github/scripts/validate-platform.js
```

يوجد أيضًا Workflow باسم **Validate App 360 Lab** يفحص سلامة الفهرس والأهداف ومسارات الفئات والتطبيقات العاملة عند تغييرات المنصة.

## القاعدة التصميمية

الفيديو يشرح أو يلهم؛ التطبيق يجب أن يطلب فعلًا وممارسة: رسم، نطق، حل، بناء، ترتيب، محاكاة قرار، تسجيل، مشروع، مراجعة أداء أو نشاط واقعي خارج الشاشة.
