# Service Template

انسخ هذا المجلد فقط عندما توجد حاجة فعلية لخدمة خادم.

قبل التنفيذ حدد:

- Capability التي تحققها الخدمة من `data/capabilities.json`.
- التطبيقات المستهلكة لها.
- API contract والإصدار.
- البيانات التي تدخل/تخرج.
- الأسرار المطلوبة.
- حدود التكلفة والمهلة والحجم.
- fallback عند تعطل الخدمة.
- سياسة الخصوصية والاحتفاظ.

لا تضف Framework ثقيلًا قبل الحاجة؛ ابدأ بعقد واضح واختبارات، ثم اختر Express/Fastify/Hono أو غيره حسب الحالة. جميع Dependencies تُدار من Workspace الجذر عبر pnpm.
