# early-child-name-audio-v1

مورد صوتي مشترك لتطبيقات الطفولة المبكرة في App360. مصدره الأصلي حزمة الصوت في `apps/1-4/drawing-writing-foundations/audio`، ورُقّي إلى `resources/` عند ظهور المستهلك الثاني الفعلي `a1-tangram` وفق Rule of Two.

يتضمن مجلد `audio/` التسجيلات والـ registry وحزم PCM المجزأة، ويُحفظ `audio-pcm-v18.js` كتوافق إضافي للأسماء القديمة مثل نور على الأجهزة القديمة. لا ينبغي نسخ هذه الملفات إلى تطبيق ثالث؛ استخدم هذا المورد المشترك مباشرة.

النسخة الأصلية داخل تطبيق الرسم تُترك مؤقتًا لتجنب كسر التطبيق الحي أثناء مرحلة الترحيل والاختبار.
