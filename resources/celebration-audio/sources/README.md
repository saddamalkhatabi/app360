# Name catalog provenance

The v2 list combines the existing 41 canonical names with 1000 additional Arabic
and Yemeni name candidates. Reading vowels were authored for the selected names.
This is a recording/review catalog, not a claim about name frequency or a listening
approval. First names can be shared by genders; callers retain the selected profile
rather than inferring gender from a name.

The following MIT-licensed lists were consulted as candidate lists. Their license
notices are retained alongside this file:

- Faker `faker/providers/person/ar_AA/__init__.py`:
  https://github.com/joke2k/faker (Copyright 2012 Daniele Faraglia).
- AKhateeb `male-first--names-in-arabic.txt` and
  `female-first-names-in-arabic.txt`:
  https://github.com/AKhateeb/arabic-names (Copyright 2018 AKhateeb).

Only selected names are included, with edited spelling/vowels and deduplicated
canonical IDs. Spelling variants and hamza/spacing forms are not extra names.
Pronunciation acceptance remains a separate, digest-bound listening review.
